## Preliminary synthesis — implications, not decisions

The discovery evidence supports these provisional design principles, subject to full-text verification before they drive final choices:

1. Small controlled GridWorlds can be scientifically legitimate when each environment/change isolates a defined robustness or adaptation question.
2. Abrupt change should have an explicit injection point so pre-change performance, immediate degradation, detection/reaction delay, recovery path and post-change performance can be measured.
3. A single final score is insufficient; immediate resilience, recovery/adaptation efficiency and post-change performance should remain distinguishable.
4. Model diversity should be conceptual, not numerical.
5. The uncertainty taxonomy should remain bounded and distinguish technically different mechanisms such as action failure and observation corruption.
6. Algorithm complexity is not automatically scientific value; advanced methods may remain references rather than implementation targets.
7. Report distributions and repeated runs.
8. Report clean-condition cost as well as disturbed-condition robustness.
9. Bounded environment complexity is a validity choice, not merely convenience.
10. A coherent thesis does not need many unrelated contributions.

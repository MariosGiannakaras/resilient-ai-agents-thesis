# Related-Work Evidence Matrix — legacy seed

**Status:** historical discovery seed only; not authoritative for current research decisions or citations.

This file predates the dedicated `MariosGiannakaras/ThesisBibliography` repository. Its `RW-*` / `TH-RW-*` identifiers, abstract-level review notes, provisional findings, and “full-text pending” states must not be used as current evidence.

## Current source of truth

The complete bibliography lifecycle and scientific review now live in `ThesisBibliography`. This repository consumes only its verified generated package under:

```text
research/bibliography/
```

Use:

- `research/bibliography/manifest.csv` for the current selected source set,
- `research/bibliography/analyses/SRC-*.md` for verified source analysis and limitations,
- `research/bibliography/evidence/SRC-*.md` for citation-ready evidence,
- `research/bibliography/SOURCE_COMMIT` for exact provenance.

Canonical references use `SRC-XXXXXXXXXX`, not the legacy `RW-*` identifiers from this file.

## Research refreshes

The required literature refresh gates still apply before protocol freeze, major writing stages, and final submission. Those searches and source-level verification are performed in `ThesisBibliography`; a new verified export is then synchronized here through the PR-based bibliography workflow.

This file is retained only to preserve the historical context of the initial research bootstrap and to prevent older agents or documentation from treating the seed matrix as current evidence.

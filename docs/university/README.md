# University and Department Requirements

This folder stores verified snapshots and links for the Πανεπιστήμιο Δυτικής Αττικής / Τμήμα Μηχανικών Πληροφορικής και Υπολογιστών.

## Rules

- Prefer current official department/university sources.
- Record retrieval date and URL.
- Preserve the original file or checksum when legally/practically appropriate.
- Mark archived or uncertain material.
- Supervisor-specific instructions override generic guidance when formally applicable and must be documented.
- Recheck all sources near final submission.

- `UNIWA_REQUIREMENTS_SNAPSHOT.md`: bootstrap summary of the official writing-guidelines PDF.

# University and Department Requirements

This folder stores verified snapshots and links for the University of West Attica and the Department of Informatics and Computer Engineering.

## Rules

- Prefer current official Department/University sources.
- Record retrieval date and URL.
- Preserve the original file or checksum when legally and practically appropriate.
- Mark archived or uncertain material explicitly.
- Supervisor-specific instructions override generic guidance when formally applicable and must be documented.
- Recheck all sources near final submission.
- Preserve exact official Greek document titles where they identify the source itself.

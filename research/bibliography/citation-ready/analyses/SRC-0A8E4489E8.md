# Non-stationary Reinforcement Learning without Prior Knowledge: An Optimal Black-box Approach

## Βιβλιογραφική ταυτότητα

- **Συγγραφείς:** Chen-Yu Wei, Haipeng Luo
- **Έτος:** 2021
- **Τύπος πηγής:** πρωτογενής θεωρητική εργασία για parameter-free non-stationary reinforcement learning
- **DOI / PMLR / URL:** Proceedings of Machine Learning Research 134, COLT 2021 — https://proceedings.mlr.press/v134/wei21b.html
- **Πρωτότυπο που ελέγχθηκε:** `πρωτότυπα/SRC-0A8E4489E8.pdf`

## Σκοπός και ερευνητικό ερώτημα

Η εργασία εξετάζει αν ένας near-optimal stationary RL algorithm μπορεί να μετατραπεί με black-box τρόπο σε non-stationary learner που επιτυγχάνει near-optimal dynamic regret χωρίς να γνωρίζει εκ των προτέρων πόσες αλλαγές θα συμβούν ή πόσο μεγάλη θα είναι η συνολική variation.

## Σύνοψη

Οι συγγραφείς προτείνουν το MASTER, μια reduction που οργανώνει πολλαπλά instances ενός base algorithm σε διαφορετικές χρονικές κλίμακες. Τα μικρότερης διάρκειας instances είναι περισσότερο ευαίσθητα σε πρόσφατες αλλαγές, ενώ stationarity tests συγκρίνουν optimistic predictions και observed rewards. Όταν κάποιο test αποτυγχάνει, το σύστημα κάνει restart.

Το κύριο θεωρητικό αποτέλεσμα είναι ότι, υπό απαιτήσεις για τον base algorithm, το MASTER πετυχαίνει dynamic-regret bounds προσαρμοσμένα τόσο στον αριθμό αλλαγών `L` όσο και στη συνολική variation `Δ`, χωρίς να γνωρίζει καμία από αυτές. Η εργασία εφαρμόζει τη reduction σε bandits, episodic tabular/linear MDPs και infinite-horizon communicating MDPs, με πρόσθετες παραδοχές και caveats στην τελευταία περίπτωση.

Για τη διπλωματική, η πηγή δεν προτείνει να υλοποιηθεί το πλήρες MASTER. Παρέχει όμως ισχυρή βάση για δύο design decisions: fixed reset periods ή fixed windows είναι oracle-tuned baselines όταν χρησιμοποιούν γνώση του change rate, ενώ adaptive detector-triggered reset πρέπει να αξιολογείται χωρίς πρόσβαση στο πραγματικό changepoint.

## Μεθοδολογία

- **Γενικό framework:** policy set και time-varying expected reward functions, με dynamic regret έναντι της optimal policy κάθε round.
- **Base algorithm requirement:** near-stationary regret guarantee και optimistic reward estimates με συγκεκριμένες concentration ιδιότητες.
- **MALG:** randomized multi-scale scheduling διαφορετικών instances του base algorithm.
- **MASTER:** δύο stationarity tests και restart όταν οι observed/optimistic discrepancies υπερβούν thresholds.
- **Non-stationarity measures:** αριθμός αλλαγών `L` και συνολική variation `Δ`.
- **Εφαρμογές:** multi-armed/contextual bandits, episodic tabular και linear MDPs, infinite-horizon communicating MDPs.
- **Εμπειρική διαδικασία:** δεν παρουσιάζεται εφαρμοσμένο benchmark· η συμβολή είναι regret-theoretic.

## Κύρια ευρήματα

1. **Fixed forgetting mechanisms απαιτούν γνώση κλίμακας αλλαγής.** Fixed-period restart, fixed sliding window ή fixed discount factor έχουν θεωρητικά suboptimal behavior ως προς τον αριθμό αλλαγών όταν η κατάλληλη κλίμακα δεν είναι γνωστή. Τεκμηρίωση: Introduction και applications discussion, PDF σελ. 1–3.
2. **Multi-scale instances επιτρέπουν detection χωρίς γνώση `L` ή `Δ`.** Short-lived instances μπορούν να αποκαλύψουν ότι μια πρόσφατη policy αποδίδει καλύτερα από το παλαιότερο optimistic envelope. Τεκμηρίωση: Section 2.3 και Figure 1, PDF σελ. 8–9.
3. **Το MASTER συνδέει detection με explicit restart.** Δύο stationarity tests ελέγχουν διαφορετικές πηγές regret και, όταν αποτυγχάνουν, ο learner ξεκινά νέο block από την αρχή. Τεκμηρίωση: Algorithm 3 και Section 3.2, PDF σελ. 10–11.
4. **Το βασικό theorem προσαρμόζεται σε αριθμό και μέγεθος αλλαγών χωρίς prior knowledge.** Υπό Assumption 1, το MASTER εγγυάται near-optimal dynamic regret σε όρους `L` και `Δ`. Τεκμηρίωση: Theorem 2, PDF σελ. 6–7.
5. **Η πλήρης parameter-free εικόνα έχει όρια.** Στα infinite-horizon communicating MDPs, όταν είναι άγνωστα `L`, `Δ` και το maximum diameter, η προτεινόμενη επέκταση πληρώνει πρόσθετο regret και το πλήρως optimal αποτέλεσμα παραμένει ανοικτό. Τεκμηρίωση: Section 4.2 και Conclusion, PDF σελ. 12–14.
6. **Η μέθοδος είναι θεωρητικά γενική αλλά πρακτικά σύνθετη.** Απαιτεί πολλαπλά scheduled learners, optimistic confidence estimates και calibrated tests· δεν είναι απλό detector wrapper για vanilla Q-learning.

## Υποθέσεις και ορισμοί

Το MASTER προϋποθέτει base algorithm με:

- near-stationary regret bound `C(t)`,
- optimistic estimate της καλύτερης reward,
- συγκέντρωση observed regret γύρω από το bound,
- κατάλληλη monotonicity/scaling του average regret.

Για τη διπλωματική, οι σχετικές experimental κατηγορίες είναι:

- **oracle periodic reset:** period επιλεγμένο με γνώση change interval,
- **non-oracle fixed reset:** period tuned μόνο σε development scenarios,
- **detector-triggered reset:** threshold χωρίς πρόσβαση στο πραγματικό onset,
- **multi-timescale score:** προαιρετικό lightweight approximation με short/long moving averages.

## Περιορισμοί και απειλές εγκυρότητας

Η εργασία είναι θεωρητική και δεν αποδεικνύει ότι το MASTER είναι πρακτικά αποδοτικό σε μικρό GridWorld ή υπό περιορισμένο CPU budget. Οι guarantees εξαρτώνται από properties του base algorithm που vanilla tabular Q-learning δεν ικανοποιεί αυτομάτως στη συγκεκριμένη black-box μορφή. Τα stationarity tests χρησιμοποιούν optimistic quantities που πρέπει να οριστούν και να βαθμονομηθούν. Οι bounds δεν πρέπει να παρουσιαστούν ως empirical recovery times.

# SRC-9D663D35D0 — Robust Markov Decision Processes without Model Estimation

## Βιβλιογραφική ταυτότητα

- **Συγγραφείς:** Wenhao Yang, Han Wang, Tadashi Kozuno, Scott M. Jordan, Zhihua Zhang
- **Έκδοση:** arXiv:2302.01248, 2023
- **Τύπος:** θεωρητική/αλγοριθμική εργασία robust RL
- **Ρόλος στη διπλωματική:** υποστηρικτική

## Αντικείμενο

Η εργασία αντιμετωπίζει δύο πρακτικά κόστη των κλασικών robust MDPs: την αποθήκευση πλήρους transition model και την υπόθεση ότι υπάρχει oracle που λύνει ακριβώς το εσωτερικό distributionally robust optimization πρόβλημα.

Προτείνει penalized robust-MDP formulation μέσω Lagrangian duality και αναπτύσσει Q-learning-type αλγορίθμους που λειτουργούν χωρίς explicit model estimation και χωρίς DRO oracle.

## Κύρια αποτελέσματα

- Η penalized formulation διατηρεί robust Bellman structure αντίστοιχη με το constrained robust MDP.
- Η προτεινόμενη model-free προσέγγιση απαιτεί αποθήκευση τάξης `O(|S||A|)` αντί `O(|S|²|A|)` για πλήρες transition model.
- Παρουσιάζονται sample-complexity guarantees τόσο με generative model όσο και με Markovian data από μία trajectory υπό behavior policy.
- Η robust Q-learning-type λύση παραμένει optimization έναντι uncertainty set· δεν ανιχνεύει changepoints και δεν αποθηκεύει recurring regimes.

## Συνάφεια με τη διπλωματική

Η πηγή είναι ιδιαίτερα χρήσιμη επειδή δείχνει ότι ένας tabular robust comparator μπορεί να σχεδιαστεί χωρίς πλήρες learned transition tensor. Αυτό είναι πιο κοντά στο resource-aware GridWorld scope από βαριές model-based robust architectures.

Δεν πρέπει όμως να συγχέεται με adaptive non-stationary RL. Η robust policy προστατεύεται έναντι model perturbations που περιγράφονται από το uncertainty formulation· δεν παρέχεται μηχανισμός για detection, reset, context recall ή post-change recovery.

## Πρωτόκολλο που προκύπτει

Για model-free robust-Q comparator πρέπει να δηλώνονται:

- μορφή divergence/uncertainty formulation,
- robustness radius ή penalty parameter,
- αν τα samples προέρχονται από generative model ή μία online trajectory,
- behavior-policy coverage,
- memory footprint,
- computation ανά update,
- clean return,
- disturbed return,
- conservativeness gap,
- performance σε shifts εντός και εκτός του assumed uncertainty family.

Η σύγκριση με plain/recency Q-learning πρέπει να χρησιμοποιεί ίδιο πραγματικό interaction budget. Generative-model queries, εάν χρησιμοποιηθούν, καταγράφονται χωριστά.

## Περιορισμοί

- Η εργασία αφορά robust optimization και όχι piecewise-stationary changepoint adaptation.
- Η απόδοση εξαρτάται από το uncertainty-set/penalty specification.
- Οι θεωρητικές assumptions και η stochastic-optimization πολυπλοκότητα μπορεί να είναι δυσανάλογες για το βασικό implementation της διπλωματικής.
- Δεν τεκμηριώνει ότι robust Q-learning ανακάμπτει ταχύτερα μετά από abrupt structural change.

## Απόφαση

**Επιλογή ως υποστηρικτική πηγή.** Χρησιμοποιείται για feasibility και resource accounting ενός model-free robust-Q comparator, όχι ως κύριος adaptive agent.

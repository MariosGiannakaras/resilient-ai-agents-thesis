# SRC-7313A97A30 — On Practical Robust Reinforcement Learning: Practical Uncertainty Set and Double-Agent Algorithm

## Βιβλιογραφική ταυτότητα

- **Συγγραφείς:** Ukjo Hwang, Songnam Hong
- **Έκδοση:** arXiv:2305.06657v3, 2023
- **Τύπος:** model-free robust RL
- **Ρόλος στη διπλωματική:** υποστηρικτική

## Ερευνητικό πρόβλημα

Η robust policy εξαρτάται κρίσιμα από το uncertainty set. Πολύ στενό set αφήνει τον agent εκτεθειμένο σε plausible model mismatch· πολύ ευρύ set περιλαμβάνει implausible MDPs και μπορεί να δημιουργήσει υπερβολικά συντηρητική policy.

Η εργασία προτείνει να αποκλειστούν ορισμένα μη ρεαλιστικά transition models από το κλασικό ambiguity set και να χρησιμοποιηθεί ένα πιο `practical uncertainty set`.

## Μέθοδοι

### ARQ-Learning

Για tabular environments προτείνεται sample-based robust Q-learning πάνω στο τροποποιημένο uncertainty set. Σύμφωνα με το abstract:

- παρέχεται finite-time error bound,
- η μέθοδος συγκλίνει με την ίδια τάξη ταχύτητας όπως standard και robust Q-learning,
- επιδιώκεται καλύτερη robustness λόγω λιγότερο παθολογικού uncertainty set.

### Double-agent architecture

Για μεγαλύτερους ή συνεχείς χώρους προτείνεται πρόσθετος pessimistic agent. Ο nominal/task agent και ο pessimistic agent παρέχουν διαφορετικές εκτιμήσεις, ώστε η policy update να ενσωματώνει model uncertainty χωρίς να απαιτεί πλήρη explicit enumeration των transition distributions.

## Συνάφεια

Η εργασία είναι χρήσιμη για δύο σχεδιαστικές αποφάσεις:

1. η μορφή του uncertainty set είναι μέρος του algorithm και πρέπει να δηλώνεται/αξιολογείται,
2. nominal και pessimistic estimates μπορούν να διατηρούνται ως χωριστά components, αντί να συγχωνεύονται σε αδιαφανές robustness score.

Για tabular GridWorld μπορεί να εξεταστεί μόνο η απλή ARQ-like λογική ή ένα nominal/pessimistic Q-table ablation. Η deep double-agent μέθοδος δεν είναι υποχρεωτική.

## Πρωτόκολλο

- Καταγραφή geometric/statistical ορισμού του uncertainty set.
- Αιτιολόγηση ποιες transition distributions αποκλείονται ως implausible.
- Sensitivity analysis ως προς uncertainty radius και exclusion rule.
- Clean return, disturbed return και worst-case return.
- Conservativeness gap σε nominal conditions.
- Διαφορά nominal και pessimistic Q estimates.
- Υπολογιστικό και memory overhead δεύτερου agent.

## Περιορισμοί

- Το repository περιέχει κυρίως arXiv abstract/metadata page και όχι πλήρη converted paper· αποφεύγονται λεπτομερείς αριθμητικοί ισχυρισμοί.
- Η επιλογή του `practical` uncertainty set απαιτεί assumptions και μπορεί να αποκλείσει τον πραγματικό deployment model.
- Η μέθοδος δεν εντοπίζει changepoints και δεν διαχειρίζεται repeated regimes.
- Robustness μέσα στο επιλεγμένο set δεν συνεπάγεται recovery από structural change εκτός set.
- Ο πρόσθετος pessimistic agent αυξάνει compute και implementation complexity.

## Απόφαση

**Επιλογή ως υποστηρικτική πηγή.** Τεκμηριώνει uncertainty-set specification και nominal–pessimistic double-agent ablation, με αυστηρή διάκριση από change adaptation.

# CARL: A Benchmark for Contextual and Adaptive Reinforcement Learning

## Βιβλιογραφική ταυτότητα

- **Συγγραφείς:** Carolin Benjamins, Theresa Eimer, Frederik Schubert, André Biedenkapp, Bodo Rosenhahn, Frank Hutter, Marius Lindauer
- **Έτος:** 2021
- **Τύπος πηγής:** επιστημονική εργασία / benchmark library
- **DOI / arXiv / URL:** arXiv:2110.02102v2 · DOI 10.48550/arXiv.2110.02102
- **Πρωτότυπο που ελέγχθηκε:** `πρωτότυπα/SRC-3F84F52F97.pdf` και `πηγές/SRC-3F84F52F97.md`

## Σκοπός και ερευνητικό ερώτημα

Η εργασία εισάγει ένα αναπαραγώγιμο benchmark για να μελετηθεί η γενίκευση RL agents μεταξύ ελεγχόμενων instances του ίδιου task. Εξετάζει πώς ο ορισμός και η ορατότητα ενός context, καθώς και η απόσταση μεταξύ train και test context distributions, επηρεάζουν τη μάθηση και τη generalization.

## Σύνοψη

Το CARL μετατρέπει γνωστά RL environments σε contextual MDP families. Κάθε instance ορίζεται από context variables που μπορούν να μεταβάλλουν transition dynamics ή reward, να είναι ορατές ή κρυφές από τον agent και να δειγματοληπτούνται από σαφώς ορισμένες distributions. Η εργασία δίνει ιδιαίτερη έμφαση στον διαχωρισμό representation learning από policy generalization και σε controlled in-distribution/out-of-distribution evaluation. Τα experiments δείχνουν ότι η μεγαλύτερη context variation δυσκολεύει τη μάθηση και ότι η ρητή παροχή context μπορεί να βελτιώσει learning/generalization, χωρίς όμως να εξασφαλίζει ισχυρή OOD generalization.

## Μεθοδολογία

- **Δεδομένα ή περιβάλλον:** contextual extensions σε OpenAI Gym classic control/Box2D, Brax, Super Mario και RNA design environments.
- **Μοντέλα / αλγόριθμοι:** DDPG για CARLPendulum, PPO για CARLMario και DQN για το LunarLander-based “Landing in Space” scenario.
- **Baselines:** context-visible έναντι context-hidden agents· διαφορετικά εύρη context variation· in-distribution έναντι out-of-distribution test instances.
- **Μετρικές:** episodic reward, training curves, test reward και crashes στο LunarLander scenario.
- **Πειραματική διαδικασία:** πέντε random seeds και 100 sampled contexts στα κύρια experiments· controlled normal distributions για context features και χωριστά ID/OOD test instances.

## Κύρια ευρήματα

1. **Το contextual MDP παρέχει καθαρό formalism για families σχετιζόμενων MDPs.** Τα instances μοιράζονται state/action spaces, ενώ transition και reward functions μπορούν να μεταβάλλονται με το context. Τεκμηρίωση: Section 2, pp. 2–3.
2. **Ο διαχωρισμός explicit από implicit context απομονώνει policy generalization από representation learning.** Όταν το context είναι κρυφό, ο agent πρέπει να το συμπεράνει από observations· όταν παρέχεται ρητά, μπορεί να χρησιμοποιηθεί απευθείας. Τεκμηρίωση: Section 4, p. 5.
3. **Οι προκαθορισμένες context bounds και distributions βελτιώνουν συγκρισιμότητα και reproducibility.** Το CARL επιτρέπει να οριστούν ελεγχόμενα train/test distributions αντί για ad hoc environment modifications. Τεκμηρίωση: Sections 1, 2 και 5, pp. 2–6.
4. **Μεγαλύτερη variation ακόμη και ενός context feature μπορεί να δυσκολέψει αισθητά ένα απλό task.** Στο CARLPendulum οι μικρές αποκλίσεις έχουν περιορισμένη επίδραση, ενώ ισχυρότερη variation μπορεί να κάνει τη μάθηση απαιτητική. Τεκμηρίωση: Section 6.1 και Figure 4a, p. 7.
5. **Η explicit context information συχνά βοηθά όταν οι αλλαγές στη dynamics είναι μεγάλες, αλλά όχι ομοιόμορφα για κάθε feature ή training phase.** Τεκμηρίωση: Section 6.2 και Figure 4b, pp. 7–8.
6. **Η καλή in-distribution επίδοση δεν συνεπάγεται ισχυρή OOD generalization.** Στο “Landing in Space” η επίδοση χειροτερεύει και τα crashes αυξάνονται καθώς η gravity απομακρύνεται από την train distribution. Τεκμηρίωση: Section 6.3 και Figure 6, pp. 8–9.

## Υποθέσεις και ορισμοί

- Ένα contextual MDP είναι οικογένεια MDP instances με κοινό state/action interface και instance-specific transition/reward functions.
- Το context είναι η πληροφορία που ορίζει το συγκεκριμένο instance και μπορεί να είναι γνωστή, θορυβώδης ή μη παρατηρήσιμη.
- In-distribution και out-of-distribution πρέπει να ορίζονται ως προς ρητή train context distribution και όχι μόνο μέσω διαφορετικών environment names.
- Το explicit context διευκολύνει policy learning αλλά αλλάζει το information set του agent, επομένως context-visible και context-hidden agents δεν είναι ταυτόσημα baselines.

## Περιορισμοί και απειλές εγκυρότητας

- Τα reported experiments εξετάζουν κυρίως static contexts, όχι dynamic context changes ή continual online adaptation.
- Μεταβάλλεται κυρίως ένα context feature κάθε φορά· simultaneous multi-factor shifts παραμένουν ανοιχτό ζήτημα.
- Η πειραματική έμφαση είναι σε featurized environments και όχι σε πλήρη μελέτη vision-based context exposure.
- Η βιβλιοθήκη εξαρτάται από πολλά τρίτα environments και απαιτεί συνεχή maintenance και έλεγχο εκδόσεων.
- Τα αποτελέσματα DDPG/DQN/PPO δεν αποδεικνύουν καθολική υπεροχή explicit context ούτε ότι το CARL πρέπει να υιοθετηθεί αυτούσιο.
- Η εργασία αφορά κατά κύριο λόγο generalization μεταξύ context instances· η resilience μετά από αιφνίδιο changepoint χρειάζεται πρόσθετο protocol.

## Σχέση με άλλες πηγές

- Εξειδικεύει το controlled generalization protocol των `SRC-0882A9B2B0` και `SRC-21EBE15D15` με συγκεκριμένο contextual benchmark design.
- Συμπληρώνει το `SRC-0F8A6588DC` (NovGrid): το CARL ορίζει context distributions και ID/OOD generalization, ενώ το NovGrid εστιάζει σε sudden novelty και recovery curves.
- Συνδέεται με `SRC-91D56A10CF` και `SRC-D14764616F`, όπου latent context, context switches και reuse χρησιμοποιούνται ως adaptation mechanisms.
- Υποστηρίζει το requirement να αποθηκεύονται resolved environment parameters και να μη χρησιμοποιούνται αόριστες ετικέτες “easy/hard” χωρίς πραγματικές distributions.

- **Τι δεν πρέπει να ισχυριστούμε από αυτή την πηγή:** ότι static-context generalization ισοδυναμεί με online resilience· ότι η explicit παροχή context είναι πάντοτε καλύτερη· ότι τα CARL numerical results μεταφέρονται αυτούσια στο GridWorld της διπλωματικής.

# SRC-6126015212 — Safe Reinforcement Learning in Constrained Markov Decision Processes

## Βιβλιογραφική ταυτότητα

- **Συγγραφείς:** Akifumi Wachi, Yanan Sui
- **Έκδοση:** ICML 2020, PMLR 119
- **Τύπος:** primary safe exploration / constrained MDP method
- **Ρόλος στη διπλωματική:** υποστηρικτική

## Αντικείμενο

Η εργασία προτείνει το SNO-MDP για περιβάλλοντα όπου η safety function είναι αρχικά άγνωστη. Ο agent ακολουθεί δύο στάδια: πρώτα επεκτείνει την πιστοποιημένη ασφαλή περιοχή και έπειτα βελτιστοποιεί cumulative reward μέσα σε αυτή.

Η safety αναπαρίσταται ως state constraint `g(s) >= h`, ενώ reward και safety functions μαθαίνονται με Gaussian-process models υπό regularity assumptions.

## Κύρια αποτελέσματα

- Ορίζονται pessimistic και optimistic safe sets.
- Η ασφαλής περιοχή λαμβάνει υπόψη όχι μόνο state-level confidence αλλά και reachability και returnability.
- Το SNO-MDP στοχεύει τόσο σε probabilistic safety guarantee όσο και σε near-optimal reward μέσα στο ασφαλές reachable region.
- Προτείνεται early stopping της safety exploration ώστε να μειώνεται το κόστος υπερβολικά μακράς exploration.
- Η αξιολόγηση περιλαμβάνει synthetic safe environment και Mars exploration scenario.

## Συνάφεια

Η πιο σημαντική συνεισφορά για τη διπλωματική είναι ότι ένα state μπορεί να φαίνεται individually safe αλλά να είναι επιχειρησιακά επικίνδυνο αν δεν υπάρχει ασφαλής διαδρομή επιστροφής. Αυτό είναι χρήσιμο σε GridWorld scenarios με hazards, blocked corridors ή αλλαγές topology.

Για safety-aware recovery μετά από perturbation δεν αρκεί να καταγράφεται εάν ο current state είναι safe. Πρέπει να εξετάζεται εάν παραμένει **returnable** σε γνωστή safe region.

## Πρωτόκολλο που προκύπτει

Σε safe GridWorld scenario προστίθενται προαιρετικά:

- safe-state set size,
- reachable-safe set size,
- returnable-safe set size,
- number of states whose safety status is uncertain,
- violation count,
- exploration steps spent only on safety learning,
- reward opportunity cost της safety exploration,
- first time at which a useful task policy can be resumed safely.

Μετά από structural change, η returnability πρέπει να επανυπολογίζεται, επειδή μια blocked edge ή νέο obstacle μπορεί να ακυρώσει παλιό safe route χωρίς να αλλάξει το local safety label ενός state.

## Περιορισμοί

- Deterministic transition structure στο formulation της εργασίας.
- Απαιτεί known initial safe set και strong GP/RKHS regularity assumptions.
- Η near-optimality αφορά το certified safe region, όχι απαραίτητα το unconstrained global optimum.
- Δεν είναι changepoint-detection ή general resilience algorithm.
- Το GP machinery είναι δυσανάλογο ως default baseline για tabular thesis implementation.

## Απόφαση

**Επιλογή ως υποστηρικτική πηγή.** Χρησιμοποιείται για reachability/returnability-aware safety metrics και για το failure mode όπου environmental change ακυρώνει μια παλιά safe route.

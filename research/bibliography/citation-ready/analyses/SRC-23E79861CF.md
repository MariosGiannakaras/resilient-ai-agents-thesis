# Επιστημονική ανάλυση — SRC-23E79861CF

## Βιβλιογραφική ταυτότητα

- **Τίτλος:** Multi-model Partially Observable Markov Decision Processes
- **Συγγραφείς:** Weiyu Li, Brian T. Denton
- **Δημοσίευση:** INFORMS Journal on Computing / Optimization Online version
- **Προτεινόμενος ρόλος:** υποστηρικτική πηγή

## Ερευνητικό πρόβλημα

Η εργασία μελετά model ambiguity σε POMDPs όταν υπάρχουν πολλαπλά αξιόπιστα μοντέλα με κοινή δομή αλλά διαφορετικές παραμέτρους. Αντί να επιλέγεται αυθαίρετα ένα μοντέλο ή να εφαρμόζεται αποκλειστικά worst-case max-min policy, η MPOMDP διατηρεί belief πάνω στα υποψήφια μοντέλα και το ενημερώνει από τα παρατηρούμενα outputs.

## Μοντελοποίηση

- Κάθε candidate model είναι πλήρες POMDP.
- Ο agent διατηρεί model-belief vector.
- Το belief ενημερώνεται online από τις παρατηρήσεις.
- Η policy μεγιστοποιεί weighted expected value στα πιθανά models.
- Η MPOMDP μπορεί να αναδιατυπωθεί ως POMDP με διευρυμένο state space.

## Κύρια ευρήματα

- Το online model belief επιτρέπει προσαρμογή της policy καθώς συσσωρεύονται observations.
- Ακόμη και αν κανένα candidate model δεν είναι ακριβώς το true model, το belief τείνει να δίνει μεγαλύτερο βάρος σε models που εξηγούν καλύτερα τα outputs.
- Η weighted-average formulation είναι λιγότερο συντηρητική από strict worst-case robust optimization.
- Παρουσιάζονται exact και approximate solution methods, με asymptotic convergence για τις approximations.

## Σχέση με τη διπλωματική

Η πηγή προσφέρει formal υπόβαθρο για **model library + online belief update**. Αυτό σχετίζεται με context recall, αλλά δεν είναι το ίδιο:

- context recall επιλέγει αποθηκευμένο regime/model,
- MPOMDP διατηρεί κατανομή πιθανότητας πάνω σε πολλά models,
- strict robust planning βελτιστοποιεί worst case χωρίς απαραίτητα να μαθαίνει ποιο model ισχύει.

Σε tabular GridWorld μπορεί να μεταφραστεί σε μικρή library πιθανών transition/reward regimes και Bayesian ή likelihood-based weighting μετά από αλλαγές.

## Πειραματικές επιπτώσεις

Πρέπει να αναφέρονται:

- candidate-model set και τρόπος δημιουργίας του,
- posterior/model weights ανά χρόνο,
- model-identification accuracy ή log-likelihood,
- performance όταν το true regime βρίσκεται ή δεν βρίσκεται στη library,
- weighted policy έναντι hard model selection,
- weighted policy έναντι worst-case policy,
- computational cost αύξησης της model library.

## Περιορισμοί

- Η εργασία αφορά partial observability και model ambiguity, όχι άγνωστα arbitrary changepoints.
- Υποθέτει πεπερασμένη/δομημένη οικογένεια candidate models.
- Η κύρια εφαρμογή είναι healthcare και finite-horizon planning, όχι online model-free RL.
- Η enlarged-state formulation μπορεί να γίνει γρήγορα υπολογιστικά ακριβή.

## Απόφαση

**Επαληθευμένη — εξαγωγή ναι, ως υποστηρικτική πηγή.** Χρησιμοποιείται για belief-weighted context/model library και για διάκριση Bayesian ambiguity από worst-case robustness.

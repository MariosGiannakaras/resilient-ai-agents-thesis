# Emergent Complexity and Zero-shot Transfer via Unsupervised Environment Design

## Βιβλιογραφική ταυτότητα

- **Συγγραφείς:** Michael Dennis, Natasha Jaques, Eugene Vinitsky, Alexandre Bayen, Stuart Russell, Andrew Critch, Sergey Levine
- **Έτος:** 2020
- **Έκδοση:** NeurIPS 2020
- **Τύπος:** πρωτογενής εργασία για unsupervised environment/curriculum design και zero-shot transfer

## Σκοπός

Η εργασία εξετάζει πώς μπορεί να παραχθεί αυτόματα μια distribution από εκπαιδευτικά περιβάλλοντα όταν ο designer καθορίζει μόνο ένα underspecified environment και όχι πλήρη task distribution. Στόχος είναι η παραγωγή δύσκολων αλλά επιλύσιμων tasks που ακολουθούν την πρόοδο του agent και βελτιώνουν τη zero-shot μεταφορά.

## Μέθοδος

Οι συγγραφείς ορίζουν το Unsupervised Environment Design (UED) και εισάγουν τον PAIRED:

- protagonist: ο policy learner που θέλουμε να εκπαιδεύσουμε,
- antagonist: δεύτερος learner που δείχνει τι είναι εφικτό,
- environment adversary: δημιουργεί parameterized environments,
- adversary reward: regret, δηλαδή η διαφορά return antagonist–protagonist.

Η regret objective αποθαρρύνει τόσο τα trivial όσο και τα αδύνατα περιβάλλοντα: ένα unsolvable environment δίνει παρόμοια χαμηλή επίδοση και στους δύο agents και συνεπώς μικρό regret.

## Κύρια ευρήματα

1. **Domain randomization και minimax adversarial design έχουν διαφορετικά failure modes.** Η τυχαία παραγωγή μπορεί να αποτύχει να δημιουργήσει δομημένες δύσκολες περιπτώσεις, ενώ ο minimax adversary μπορεί να καταλήξει σε μη επιλύσιμα tasks.
2. **Το minimax regret στοχεύει difficult-but-solvable environments.** Ο antagonist λειτουργεί ως feasibility witness για τον adversary.
3. **Παράγεται αυτόματο curriculum.** Καθώς ο protagonist βελτιώνεται, ο adversary πρέπει να αυξάνει τη δυσκολία για να διατηρεί υψηλό regret.
4. **Στα navigation experiments ο PAIRED δημιουργεί πιο σύνθετους λαβυρίνθους.** Οι μετρικές περιλαμβάνουν blocks, distance, passable path length και solved path length, με πέντε seeds και 95% confidence intervals.
5. **Οι policies παρουσιάζουν υψηλότερο zero-shot transfer σε hand-designed mazes και σε modified MuJoCo parameters από τα συγκεκριμένα domain-randomization/minimax baselines.**
6. **Πρόκειται για train-time generalization, όχι online resilience.** Μετά την εκπαίδευση, η policy αξιολογείται frozen σε unseen environments· δεν υπάρχει continued learning ή recovery window.

## Σχέση με τη διπλωματική

Η πηγή είναι χρήσιμη κυρίως για το design των training/test distributions και για stress-test generation:

- procedural generation διαφορετικών layouts,
- δυσκολία που παραμένει solvable,
- held-out hand-designed challenge environments,
- αποφυγή trivial randomization και impossible adversarial cases,
- σαφής διάκριση zero-shot robustness από post-change adaptation.

Ο PAIRED δεν προτείνεται ως βασική υλοποίηση, διότι απαιτεί τρεις συν-εκπαιδευόμενους agents και σημαντικό compute. Η ιδέα minimax-regret environment selection μπορεί να μεταφερθεί απλούστερα ως offline scenario curation ή adaptive test generator.

## Πρωτόκολλο που προκύπτει

- train/test level distributions με disjoint seeds,
- solvability check για κάθε generated layout,
- difficulty metrics πέρα από obstacle count,
- frozen-policy zero-shot evaluation πριν από online adaptation,
- separate labels `environment_generation_method` και `agent_adaptation_method`,
- reporting compute cost της curriculum generation,
- hand-designed edge cases μαζί με procedural test distribution.

## Περιορισμοί

Η PAIRED training διαδικασία είναι multi-agent/adversarial και computationally expensive. Η θεωρητική minimax-regret characterization βασίζεται σε equilibrium/coordination assumptions. Τα navigation και Hopper results δεν αποδεικνύουν ότι η ίδια curriculum ordering θα ισχύσει σε κάθε GridWorld. Το benchmark design πρέπει να παραμένει ανεξάρτητο από το τελικό test set ώστε να αποφεύγεται leakage.

# Uncertainty-Based Out-of-Distribution Detection in Deep Reinforcement Learning

## Βιβλιογραφική ταυτότητα
Andreas Sedlmeier, Thomas Gabor, Thomy Phan, Lenz Belzner, Claudia Linnhoff-Popien. Preprint/work in progress, arXiv:1901.02219.

## Σκοπός και ερευνητικό ερώτημα
Εξετάζει αν η epistemic uncertainty του ίδιου του value network μπορεί να χρησιμοποιηθεί για διάκριση in-distribution και out-of-distribution καταστάσεων σε deep value-based RL.

## Σύνοψη
Η εργασία συγκρίνει Monte-Carlo dropout, Concrete Dropout, bootstrap ensembles και bootstrap ensembles με randomized prior. Χρησιμοποιεί ελεγχόμενο GridWorld όπου το test/mirror environment αντιστρέφει περιοχές start/goal και συνεπώς αναγκάζει τον agent να επισκεφθεί καταστάσεις που δεν εμφανίστηκαν στην εκπαίδευση. Τα bootstrap-based σχήματα έδωσαν πιο σταθερό διαχωρισμό ID/OOD από τα dropout-based σχήματα.

## Μεθοδολογία
- value-based deep RL / DQN-like setting,
- 12×4 GridWorld,
- ξεχωριστή train και mirror OOD αξιολόγηση,
- uncertainty από πολλαπλά stochastic forward passes ή ensemble heads,
- 30 evaluation runs και 10,000 training episodes,
- η evaluation εμπειρία δεν επιστρέφει στην εκπαίδευση.

## Κύρια ευρήματα
1. Epistemic uncertainty μπορεί να παρέχει OOD signal σε RL, αλλά η ποιότητά του εξαρτάται έντονα από τον estimator.
2. Bootstrap και bootstrap-prior παρήγαγαν πιο σταθερά υψηλότερη uncertainty στο OOD environment.
3. MC-dropout variants δεν διατήρησαν αξιόπιστο separation σε όλη την εκπαίδευση.
4. Η ίδια uncertainty scale μεταβάλλεται όσο ο agent μαθαίνει, άρα fixed threshold χωρίς calibration/time-aware validation είναι επισφαλές.

## Υποθέσεις και ορισμοί
Η εργασία χειρίζεται OOD ως καταστάσεις χαμηλής training-data density. Αυτό δεν είναι ισοδύναμο με environmental changepoint: δεν υπάρχει online transition από regime A σε B και δεν μετρώνται false alarms ή detection delay σε συνεχή trajectory.

## Περιορισμοί και απειλές εγκυρότητας
- preprint/work in progress,
- μικρό deterministic GridWorld,
- OOD mirror split σχεδιασμένο εκ των προτέρων,
- deep neural uncertainty και όχι tabular detector,
- static evaluation snapshots, όχι sequential detection,
- περιορισμένη τεκμηρίωση stochastic environments.

## Σχέση με άλλες πηγές
Συμπληρώνει το `SRC-19C2E91926`, που δίνει ευρύτερο RL-OOD benchmark με physical-parameter shifts και observation corruptions. Σε σχέση με `SRC-70AEC665B2`, δείχνει γιατί uncertainty score χρειάζεται calibration και δεν είναι αυτομάτως probability.

## Χρήση στη διπλωματική
Υποστηρικτική πηγή για optional neural detector arm και για GridWorld OOD diagnostics. Στο κύριο protocol:
- uncertainty estimator δεν βαφτίζεται change detector χωρίς sequential validation,
- report threshold/calibration split,
- report false-alarm rate, missed-change rate και detection delay,
- κρατάμε χωριστά observation OOD και transition/dynamics change.

## Απαιτούμενα αποσπάσματα
1. Η epistemic uncertainty αυξάνει σε περιοχές χαμηλής training density.
2. Τα bootstrap-based σχήματα ήταν πιο αξιόπιστα από dropout variants στο συγκεκριμένο GridWorld.
3. Το mirror environment δημιουργεί controlled OOD states χωρίς να χρησιμοποιεί evaluation data για training.
4. Η εργασία δεν αποδεικνύει sequential changepoint detection.

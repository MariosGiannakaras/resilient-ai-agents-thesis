# SRC-52E62452B8 — Robust Control of Markov Decision Processes with Uncertain Transition Matrices

## Βιβλιογραφική ταυτότητα

- **Συγγραφείς:** Arnab Nilim, Laurent El Ghaoui
- **Έκδοση:** Operations Research, 53(5), 2005, pp. 780–798
- **DOI:** 10.1287/opre.1050.0216
- **Τύπος:** θεμελιώδης θεωρητική εργασία robust MDP
- **Ρόλος στη διπλωματική:** κύρια θεωρητική πηγή για robust-MDP baseline design

## Αντικείμενο

Η εργασία εξετάζει finite-state, finite-action MDPs όταν οι transition probabilities δεν είναι γνωστές ακριβώς αλλά ανήκουν σε uncertainty sets. Το βασικό πρόβλημα είναι ότι η nominal optimal policy μπορεί να είναι εξαιρετικά ευαίσθητη σε μικρά estimation errors των transition matrices.

Οι συγγραφείς διατυπώνουν minimax robust-control πρόβλημα, με τον controller να επιλέγει policy και τη «φύση» να επιλέγει transition model μέσα στο επιτρεπτό uncertainty set.

## Κύρια αποτελέσματα

- Υπό rectangular uncertainty structure, το robust control problem επιδέχεται δυναμικό προγραμματισμό με robust Bellman recursion.
- Για συγκεκριμένες uncertainty-set κατασκευές, όπως likelihood regions και relative-entropy bounds, η robust recursion παραμένει υπολογιστικά κοντά στην κλασική dynamic-programming recursion.
- Η εργασία διακρίνει stationary uncertainty από time-varying uncertainty. Η δεύτερη είναι tractable μέσω robust DP αλλά αντιπροσωπεύει ισχυρότερη worst-case υπόθεση.
- Πολύ απλά interval/polytopic uncertainty sets μπορεί να είναι στατιστικά φτωχά και να παράγουν υπερβολικά conservative policies.
- Στο path-planning παράδειγμα η robust policy βελτιώνει τη worst-case performance όταν το transition model είναι αβέβαιο.

## Συνάφεια με τη διπλωματική

Η εργασία είναι θεμελιώδης για να οριστεί τι σημαίνει **robustness σε αβεβαιότητα μοντέλου** πριν εξεταστεί η **resilience μετά από πραγματική αλλαγή περιβάλλοντος**.

Για το πειραματικό GridWorld επιτρέπει να οριστεί καθαρά ένας robust baseline:

1. nominal transition model,
2. explicit transition uncertainty set,
3. robust Bellman backup,
4. evaluation εντός και εκτός του assumed set.

Η robust policy δεν πρέπει να ερμηνεύεται ως adaptive agent. Η policy μπορεί να είναι στατική και να έχει σχεδιαστεί για worst-case model mismatch χωρίς να ανιχνεύει changepoints ή να ενημερώνεται μετά από αλλαγή.

## Πρωτόκολλο που προκύπτει

Για κάθε robust-MDP experiment καταγράφονται:

- uncertainty-set family,
- radius/size του uncertainty set,
- nominal transition model,
- εάν το true post-change model ανήκει ή όχι στο set,
- nominal return,
- disturbed/worst-case return,
- conservativeness gap,
- compute cost του robust backup.

Πρέπει επίσης να διαχωρίζονται:

- **stationary model uncertainty**: ένα άγνωστο αλλά σταθερό true model,
- **time-varying uncertainty**: η φύση μπορεί να αλλάζει model σε κάθε βήμα,
- **piecewise-stationary changepoint**: το περιβάλλον αλλάζει σε διακριτές χρονικές στιγμές και ο agent συνεχίζει να μαθαίνει.

Αυτά δεν είναι ισοδύναμα πειραματικά καθεστώτα.

## Περιορισμοί

- Η θεωρία βασίζεται σε structured/rectangular uncertainty assumptions.
- Worst-case robustness μπορεί να είναι υπερβολικά conservative όταν το uncertainty set είναι ευρύ ή poorly calibrated.
- Δεν παρέχεται change detector, context recall ή explicit post-change recovery mechanism.
- Τα αποτελέσματα δεν αποδεικνύουν ότι robust DP υπερέχει έναντι continual Q-learning ή reset σε abrupt non-stationarity.

## Απόφαση

**Επιλογή ως κύρια θεωρητική πηγή.** Θεμελιώνει το robust-MDP comparator και, κυρίως, αποτρέπει τη σύγχυση ανάμεσα σε worst-case robustness και online resilience.

# Evidence — Learn to Human-level Control in Dynamic Environment Using Incremental Batch Interrupting Temporal Abstraction

## E1 — Option interruption allows a macro-action to terminate when continuation becomes inferior

- **Type:** faithful paraphrase
- **Location:** Sections 3.1–3.4
- **Claim:** I-QOption augments option-based Q-learning with an interruption rule so an executing option need not continue to its original termination condition when another choice becomes preferable.
- **Status:** verified

### Faithful paraphrase

The paper starts from the standard option framework, where an option follows its internal policy until termination, and adds an interruption mechanism designed for dynamic environments. During execution, the agent can compare the value of continuing the current temporal abstraction with alternative choices and terminate the option early when continuation is no longer appropriate.

### Context and limits

This is adaptation inside a predefined hierarchy. It is not an explicit environmental changepoint detector.

### Thesis use

If temporal abstraction is explored, record option starts, interruptions, durations, and the policy/value criterion that triggered each interruption.

### Citation

Fu et al. (2016), Sections 3.1–3.4.

## E2 — The experiments use dynamic GridWorlds with changing obstacles

- **Type:** faithful paraphrase
- **Location:** Sections 4.1–4.3
- **Claim:** I-QOption is evaluated in four-room and six-room gridworld tasks where obstacle configurations can change between episodes.
- **Status:** verified

### Faithful paraphrase

The experimental domains are discrete navigation problems with room structure, goals, primitive actions, and predefined options. Additional obstacles alter feasible paths in the dynamic versions, requiring the option-based agent to avoid persisting with a macro-action that no longer fits the current layout.

### Context and limits

The environment variation is episode-based and is not framed as an unknown within-episode piecewise-stationary changepoint with detection-delay evaluation.

### Thesis use

Use the paper as supporting evidence for controlled structural obstacle changes, not as evidence for changepoint detection.

### Citation

Fu et al. (2016), Sections 4.1–4.3.

## E3 — The reported early-learning benefit is confounded by a predefined option library

- **Type:** faithful paraphrase
- **Location:** Sections 4.2–4.4; Figures 4–6
- **Claim:** I-QOption reaches goals in fewer steps early in learning and converges somewhat faster than primitive Q-learning in the reported tasks, but it receives useful temporal abstractions as prior knowledge.
- **Status:** verified

### Faithful paraphrase

The comparisons show faster early progress for the interruptible option learner in the studied gridworlds. At the same time, the hierarchical agent begins with reusable macro-actions that encode task structure unavailable to the primitive Q-learning baseline, so the improvement cannot be attributed only to the interruption rule.

### Thesis use

Any hierarchical comparator must expose the construction cost and contents of its option library and should include a non-interruptible option ablation.

### Citation

Fu et al. (2016), Sections 4.2–4.4 and Figures 4–6.

## E4 — The option library is a prior-information advantage

- **Type:** faithful paraphrase
- **Location:** Sections 4.2–4.3
- **Claim:** The evaluated agents are supplied with several predefined options in addition to primitive actions.
- **Status:** verified

### Faithful paraphrase

The four-room and six-room experiments provide domain-specific option sets before learning. These macro-actions summarize useful routes or subtask structure and therefore reduce the search problem relative to learning solely from primitive actions.

### Thesis use

Account for option design as prior knowledge rather than treating the hierarchical agent and primitive learner as capability-matched baselines.

### Citation

Fu et al. (2016), Sections 4.2–4.3.

## E5 — Dynamic-option control is not a full resilience protocol

- **Type:** scope inference grounded in the experimental design
- **Location:** Sections 3–4
- **Claim:** The paper evaluates control under changing obstacles and option interruption but does not measure false alarms, changepoint delay, repeated-regime recall, or post-change recovery time.
- **Status:** verified

### Thesis use

Classify I-QOption as a hierarchical dynamic-control mechanism rather than a detector-triggered resilience baseline.

### Citation

Fu et al. (2016), overall method and experimental scope.

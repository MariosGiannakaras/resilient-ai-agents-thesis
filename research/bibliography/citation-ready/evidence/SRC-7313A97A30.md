# Evidence — On Practical Robust Reinforcement Learning: Practical Uncertainty Set and Double-Agent Algorithm

## E1 — The uncertainty set is a modeling decision, not a neutral container
- **Type:** faithful paraphrase
- **Location:** Abstract
- **Claim:** The paper motivates a refined uncertainty set that removes implausible perturbed MDPs from broader robust sets.
- **Status:** verified

### Faithful paraphrase
Hwang and Hong argue that conventional robust sets can contain transition models that are technically allowed by the uncertainty definition but implausible for the actual deployment mismatch. Their practical uncertainty set is designed to exclude part of this overly pessimistic model family so that robust optimization does not hedge against every mathematically admissible perturbation indiscriminately.

### Thesis use
Treat uncertainty-set radius and exclusion rules as explicit hyperparameters/assumptions and perform sensitivity analysis rather than tuning them on the final test shifts.

### Citation
Hwang and Hong (2023), Abstract.

## E2 — ARQ-Learning is a tabular sample-based robust-Q method
- **Type:** faithful paraphrase
- **Location:** Abstract
- **Claim:** The paper introduces ARQ-Learning for tabular robust reinforcement learning under the refined uncertainty set and derives a finite-time error bound.
- **Status:** verified

### Faithful paraphrase
ARQ-Learning is presented as a sample-based tabular method that learns robust action values for the proposed practical uncertainty set. The authors state that its convergence rate is of the same order as standard Q-learning and robust Q-learning while reporting stronger robustness under their uncertainty construction.

### Context and limits
The abstract-level rate statement concerns theoretical convergence order, not equal wall-clock cost or guaranteed superior recovery after an environmental changepoint.

### Thesis use
Use ARQ-like logic only as a feasibility comparator between nominal Q-learning and a lightweight robust-Q variant.

### Citation
Hwang and Hong (2023), Abstract.

## E3 — The double-agent design adds a pessimistic estimator for model uncertainty
- **Type:** faithful paraphrase
- **Location:** Abstract
- **Claim:** The paper introduces an additional pessimistic agent to extend the practical robust-learning idea beyond the small tabular setting.
- **Status:** verified

### Faithful paraphrase
To address the main bottleneck in scaling the tabular ARQ idea, the authors introduce a second, pessimistic agent whose estimates are used to represent adverse model uncertainty alongside the nominal learning process. This architecture is then incorporated into model-free robust-RL algorithms for larger or continuous state spaces.

### Thesis use
If a neural robust comparator is considered, log nominal and pessimistic estimates separately and count the second estimator's memory/compute overhead.

### Citation
Hwang and Hong (2023), Abstract.

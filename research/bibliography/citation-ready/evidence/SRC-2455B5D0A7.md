# Evidence — A Comprehensive Survey on Test-Time Adaptation under Distribution Shifts

## Evidence E1 — Test-time adaptation is not frozen zero-shot generalization
- **Type:** faithful paraphrase
- **Location:** Abstract; Introduction; Figure 1
- **Claim:** TTA adapts a pretrained model using target/test data during the test phase, whereas domain generalization aims to perform on unseen domains without learning from target test data.
- **Thesis use:** phase separation
- **Topics:** test-time adaptation; zero-shot generalization; information budget
- **Status:** verified

### Faithful paraphrase
Test-time adaptation is defined by allowing a pretrained source model to update using unlabeled target data before or while producing test predictions. This gives the adaptive method information that a frozen zero-shot model does not receive. A post-shift update should therefore be reported as adaptation rather than as zero-shot robustness or generalization.

## Evidence E2 — TTA protocols differ in how much target data they can reuse
- **Type:** faithful paraphrase
- **Location:** Introduction; Figure 1
- **Claim:** TTDA, TTBA, and OTTA differ in target-data availability, batching, number of passes, and whether knowledge is carried between test batches.
- **Thesis use:** adaptation-budget disclosure
- **Topics:** TTDA; TTBA; OTTA; replay; update frequency
- **Status:** verified

### Faithful paraphrase
Test-time domain adaptation can use an entire target dataset and multiple adaptation epochs; test-time batch adaptation operates on one or a few batches independently; online test-time adaptation processes a stream sequentially, generally seeing each mini-batch once while carrying information learned from earlier batches. These protocols are not directly comparable without matching their information and compute budgets.

## Evidence E3 — Online adaptation must respect causal stream order
- **Type:** faithful paraphrase
- **Location:** Section 5.1, online test-time adaptation definition
- **Claim:** OTTA processes target batches sequentially and can use past but not future test data for the current adaptation step.
- **Thesis use:** causal evaluation
- **Topics:** streaming data; online update; future leakage
- **Status:** verified

### Faithful paraphrase
An online adaptive model receives target batches in sequence and can preserve state learned from previously observed batches. Future batches are not available when the current prediction/update is made. In RL the same causal constraint is even more important because the agent's actions influence the data it will observe next.

## Evidence E4 — Continual test-time adaptation can accumulate errors and forget earlier contexts
- **Type:** faithful paraphrase
- **Location:** continual/online TTA discussion in Section 5
- **Claim:** Repeated self-adaptation under changing target distributions can produce error accumulation and catastrophic forgetting.
- **Thesis use:** recurring-regime diagnostics
- **Topics:** error accumulation; forgetting; continual shift
- **Status:** verified

### Faithful paraphrase
Updating a model continuously on its own test-time signals can cause mistakes to reinforce subsequent updates, especially as the target distribution changes. Performance on the current context can improve while competence on earlier contexts deteriorates, so returning to a previously seen regime is a useful retention test.

## Evidence E5 — Resource and protocol constraints are part of adaptation quality
- **Type:** faithful paraphrase
- **Location:** Section 7, open problems
- **Claim:** Memory-efficient continual adaptation, on-the-fly operation, and consistent evaluation remain important open issues.
- **Thesis use:** resource-aware reporting
- **Topics:** memory; compute; evaluation protocol
- **Status:** verified

### Faithful paraphrase
A practical adaptive method should not be judged only by target accuracy or return. Its memory requirements, adaptation computation, access to source data, and the number of target-data passes determine whether the comparison is operationally fair and whether the method can plausibly run online.

## Avoid overclaiming
This survey concerns predictive models rather than sequential-control policies. Its main value for the thesis is the information-budget and phase-separation logic: frozen zero-shot evaluation, online adaptation, and continual adaptation must be reported as different protocols.

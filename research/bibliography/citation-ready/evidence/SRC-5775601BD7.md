# Evidence — Loss of Plasticity in Continual Deep Reinforcement Learning

## Evidence E1 — Switching ALE evaluates repeated regime changes without resetting the learner
- **Type:** faithful paraphrase
- **Location:** Sections 1 and 3.1
- **Claim:** A single deep-RL agent cycles through a fixed sequence of Atari games while retaining its learned parameters and replay state across environment switches.
- **Thesis use:** repeated-change protocol
- **Topics:** continual learning; repeated visits; no reset
- **Status:** verified

### Faithful paraphrase
Switching ALE changes the environment by moving one agent through a repeated sequence of games. The learner spends a fixed interaction budget in each game and switches without resetting the neural network weights or replay buffer, allowing later visits to reveal whether the same learner can continue to acquire competence over a long sequence of non-stationary regimes.

### Limitation
Changing the Atari game alters many aspects of the task simultaneously and is more severe than a single-axis transition or reward perturbation.

## Evidence E2 — Relearning ability can deteriorate on successive visits
- **Type:** faithful paraphrase
- **Location:** Section 3.2; Figure 2
- **Claim:** Rainbow often learns more slowly and reaches lower performance each time it revisits the same game.
- **Thesis use:** per-occurrence recovery metrics
- **Topics:** relearning; plasticity; repeated recovery
- **Status:** verified

### Faithful paraphrase
In Switching ALE, the agent can perform well during its first exposure to a game and then show progressively poorer learning on later visits. The reported curves show slower learning and lower end-of-visit performance, eventually reaching visits with little sign of improvement.

### Thesis-safe implication
Recovery should be indexed by occurrence number in repeated-change experiments rather than averaged into a single post-change score.

## Evidence E3 — A reset-from-scratch agent is a plasticity diagnostic
- **Type:** faithful paraphrase
- **Location:** Section 3.2; Figure 2
- **Claim:** The paper uses an idealized reset agent to represent how a fresh learner would relearn each game if prior tasks neither helped nor harmed its ability to learn.
- **Thesis use:** reset comparator
- **Topics:** reset; relearning capacity; interference
- **Status:** verified

### Faithful paraphrase
The reset comparator discards previous weights, replay contents, and optimizer state so that every visit corresponds to fresh learning. It forgets all prior competence, but it preserves the ability to reach approximately the same scratch-learning performance on every visit. A continual learner that falls below this reference can therefore be diagnosed as having lost part of its ability to learn, not merely as having forgotten a previously stored solution.

### Limitation
The reset agent is a diagnostic comparator, not an inherently resilient strategy.

## Evidence E4 — Loss of plasticity has neural signatures in deep value-based agents
- **Type:** faithful paraphrase
- **Location:** Sections 4–6 and Conclusion
- **Claim:** The analysis links deteriorating continual learning with increasingly sparse activation patterns and diminishing gradients.
- **Thesis use:** optional deep-agent diagnostics
- **Topics:** activations; gradients; neural plasticity
- **Status:** verified

### Faithful paraphrase
As continual training proceeds, the paper observes changes in network activations and gradients that accompany the loss of learning capacity. A simple activation-function change, Concatenated ReLU, mitigates some of this plasticity loss in the studied deep value-based agents.

### Limitation
These diagnostics are specific to neural agents and should not be used to explain slow recovery in tabular Q-learning.

## Evidence E5 — Preserving plasticity does not eliminate interference
- **Type:** faithful paraphrase
- **Location:** later experiments, including the CReLU analysis
- **Claim:** Improving the network's ability to keep learning does not automatically prevent destructive interference from previous tasks.
- **Thesis use:** retention/plasticity distinction
- **Topics:** plasticity; catastrophic interference; retention
- **Status:** verified

### Faithful paraphrase
The CReLU intervention can improve continued learning capacity while gaps relative to uninterrupted single-game training still remain or grow in some games. Plasticity and interference are therefore related but distinct failure modes: an agent may remain capable of updating while still carrying harmful effects from previous learning.

## Evidence E6 — Very expensive continual experiments constrain statistical certainty
- **Type:** faithful paraphrase
- **Location:** experimental discussion and footnotes around Section 3.2
- **Claim:** Some experiments span extremely large interaction budgets and are averaged over a small number of runs because of computational cost.
- **Thesis use:** uncertainty/reporting discipline
- **Topics:** compute budget; seeds; statistical uncertainty
- **Status:** verified

### Faithful paraphrase
The paper reports experiments lasting up to very large numbers of environment interactions and substantial wall-clock time. The authors consequently treat some results as demonstrative rather than as proof that the same failure must occur in every deep continual-learning configuration.

## Avoid overclaiming
Loss of plasticity, catastrophic forgetting, and negative transfer should not be treated as synonyms. The source supports a deep-agent plasticity diagnosis and repeated-regime protocol; it does not imply that neural mitigations such as CReLU belong in the tabular thesis core.

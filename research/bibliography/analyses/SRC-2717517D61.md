# OmniSafe — software repository

## Τύπος υλικού

Το source record είναι scrape του GitHub repository `PKU-Alignment/omnisafe`, ενός modular software framework που υλοποιεί safe reinforcement-learning algorithms και συνδέεται με Safety-Gymnasium environments.

## Πρακτική αξία

Το repository μπορεί να είναι χρήσιμο αργότερα για:

- feasibility checks deep safe-RL baselines,
- έλεγχο διαθέσιμων implementations,
- κοινό logging utility/cost metrics,
- reference configurations για CPO, PPO-Lagrangian, CRPO και άλλα algorithms.

## Γιατί δεν αποτελεί ανεξάρτητο scientific evidence

- Είναι software artifact και README, όχι ελεγχόμενη πειραματική μελέτη του ερευνητικού ερωτήματος της διπλωματικής.
- Η λίστα υλοποιημένων algorithms δεν αποδεικνύει correctness, fairness ή superiority.
- Τα benchmark αποτελέσματα και οι default hyperparameters μπορεί να αλλάζουν ανά version.
- Η ύπαρξη κώδικα δεν αντικαθιστά την πρωτογενή δημοσίευση κάθε method.
- Το framework επικεντρώνεται κυρίως σε deep SafeRL και continuous-control suites, ενώ το βασικό scope της διπλωματικής παραμένει resource-aware GridWorld.

## Απόφαση

Το repository διατηρείται ως implementation/discovery resource αλλά δεν εξάγεται ως βιβλιογραφικό evidence. Εάν χρησιμοποιηθεί κώδικας του στο τελικό implementation, θα αναφερθεί ως software dependency μαζί με συγκεκριμένη έκδοση/commit, ξεχωριστά από τις επιστημονικές πηγές.

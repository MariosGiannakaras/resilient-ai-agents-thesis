# Context-Switching and Adaptation: Brain-Inspired Mechanisms for Handling Environmental Changes

## Βιβλιογραφική ταυτότητα

- **Συγγραφείς:** Eric Chalmers, Edgar Bermudez Contreras, Brandon Robertson, Artur Luczak, Aaron Gruber
- **Έτος:** 2016
- **Τύπος πηγής:** πρωτογενής πειραματική εργασία συνεδρίου
- **DOI / arXiv / URL:** DOI:10.1109/IJCNN.2016.7727651
- **Πρωτότυπο που ελέγχθηκε:** `πρωτότυπα/SRC-D14764616F.pdf`

## Σκοπός και ερευνητικό ερώτημα

Η εργασία εξετάζει γιατί conventional model-based reinforcement learning μπορεί να προσαρμόζεται αργά όταν αλλάζουν ξαφνικά οι transitions ή οι contingencies ενός γνώριμου task. Προτείνει δύο μηχανισμούς: hierarchical state abstraction για γρήγορη προσαρμογή παλαιού μοντέλου και context switching για αποθήκευση, αναγνώριση και επαναφορά πολλαπλών μοντέλων περιβάλλοντος.

Η συνάφεια με τη διπλωματική είναι ιδιαίτερα ισχυρή: χρησιμοποιείται GridWorld, ο goal παραμένει σταθερός, αλλά οι διαδρομές και οι transition contingencies αλλάζουν επανειλημμένα. Αυτό αντιστοιχεί λειτουργικά στους «μεταβαλλόμενους κανόνες» της επίσημης αίτησης. Η πηγή δεν καθιστά το GridWorld επίσημη απαίτηση· δείχνει όμως ότι αποτελεί κατάλληλο ελεγχόμενο testbed για repeated changes και model reuse.

## Σύνοψη

Οι συγγραφείς υποστηρίζουν ότι μετά από αλλαγή περιβάλλοντος οι παλιές value estimates και ο παλιός transition model μπορούν να παραπλανούν τον agent. Στο παράδειγμα GridWorld, εμπόδια που υπήρχαν στο προηγούμενο maze παραμένουν στη μνήμη του μοντέλου, οπότε η planning διαδικασία μπορεί να θεωρεί λανθασμένα ότι δεν υπάρχει διαδρομή προς τον goal.

Η hierarchical representation ομαδοποιεί γειτονικές states σε macro-states σε πολλαπλά επίπεδα. Οι high-level value gradients επηρεάζονται λιγότερο από τοπικές αλλαγές και μπορούν να θέτουν subgoals, ενώ τα χαμηλότερα επίπεδα ανασχεδιάζουν τη λεπτομερή διαδρομή. Το context-switching component διατηρεί history πρόσφατων transitions, συγκρίνει την πιθανότητά τους υπό το τρέχον μοντέλο και, όταν η συμβατότητα πέσει κάτω από threshold, επιλέγει αποθηκευμένο μοντέλο ή δημιουργεί νέο.

Η αξιολόγηση συγκρίνει context switching με hierarchical adaptation, context switching χωρίς adaptation και conventional model-based RL σε οκτώ 16×48 GridWorlds. Κάθε environment χρησιμοποιείται για δέκα trials και η ακολουθία επαναλαμβάνεται. Το combined σύστημα επιτυγχάνει καλύτερη cumulative reward επειδή επαναφέρει παλιές λύσεις σε επανεμφανιζόμενα contexts και προσαρμόζει σχετικά μοντέλα σε νέες διατάξεις.

## Μεθοδολογία

- **Περιβάλλον:** οκτώ μεγάλα discrete GridWorlds 16×48 με σταθερό goal και διαφορετικές wall/route contingencies.
- **Task sequence:** δέκα trials ανά environment, μετά switch στο επόμενο· η πλήρης ακολουθία οκτώ environments επαναλαμβάνεται δύο φορές.
- **Episode termination:** επίτευξη goal ή 5.000 steps.
- **Rewards:** +10 στον goal, −0.1 για σύγκρουση με wall και −0.01 για άλλες transitions.
- **Agents:** conventional tabular model-based RL, context switching μόνο, context switching συν hierarchical state abstraction/adaptation.
- **Planning:** prioritized sweeping και A* hierarchical route planning.
- **Detection:** likelihood πρόσφατου transition history μήκους 20, με threshold 0.05 για model mismatch.
- **Compute fairness:** έως 120 model updates ανά step για conventional agent και ισοδύναμο συνολικό budget 20 updates × 6 hierarchy levels.
- **Repetitions:** 200 repetitions· αναφορά median cumulative reward με 25ο/75ο percentile.

## Κύρια ευρήματα

1. **Οι παλιές value gradients μπορεί να γίνουν ενεργά παραπλανητικές μετά από rule ή transition change.** Αν οι παλιές barriers παραμένουν στο model, η planning διαδικασία μπορεί να θεωρεί ότι ο νέος goal path είναι αδύνατος και να χρειάζεται τυχαία εξερεύνηση για να διορθωθεί. Τεκμηρίωση: σελίδες 1–2, Figure 1.
2. **Detection και adaptation είναι ξεχωριστά components.** Το transition-history likelihood χρησιμοποιείται για αναγνώριση ότι το current model δεν εξηγεί πλέον τα δεδομένα. Μετά το detection, ο agent πρέπει να επιλέξει existing model, να προσαρμόσει παρόμοιο model ή να μάθει νέο. Τεκμηρίωση: Sections II.B–II.C και Figure 5.
3. **Η επανεμφάνιση παλιού context επιτρέπει πολύ ταχύτερη recovery μέσω model recall.** Στη δεύτερη έκθεση στα ίδια environments, το context-switching σύστημα ανακαλεί τις αντίστοιχες λύσεις αντί να ξεκινά από μηδενική γνώση. Τεκμηρίωση: σελίδες 6–7, Figures 7–9.
4. **Η hierarchical adaptation βοηθά κυρίως όταν υπάρχει κατάλληλο σχετικό model.** Τα coarse representations διατηρούν κατεύθυνση προς τον goal, ενώ τα lower levels προσαρμόζουν τη διαδρομή. Η βελτίωση δεν εμφανίζεται όταν κανένα model της library δεν αποτελεί χρήσιμο starting point. Τεκμηρίωση: Sections II.A, IV και V.
5. **Το repeated-environment protocol είναι χρήσιμο για resilience.** Η ακολουθία νέων και επανεμφανιζόμενων contexts αποκαλύπτει διαφορετικές ικανότητες: first-time adaptation, retention, recall και compositional reuse. Τεκμηρίωση: Section III και Figures 7–9.
6. **Η model library εισάγει νέα failure modes.** Wrong context identification, duplicate models, memory growth και hierarchical suboptimality μπορούν να μειώσουν την επίδοση. Τεκμηρίωση: σελίδα 7, Discussion.

## Υποθέσεις και ορισμοί

Το paper αντιμετωπίζει κάθε περιβαλλοντική configuration ως διαφορετικό context ή MDP, με κοινά state/action spaces και ίδιο goal. Η αλλαγή εντοπίζεται όταν η πιθανότητα των πρόσφατων observed transitions υπό το current model γίνεται πολύ μικρή. Η recovery μπορεί να προκύψει από:

- **recall:** επαναφορά ήδη μαθημένου model,
- **adaptation:** τροποποίηση παρόμοιου model,
- **relearning:** δημιουργία νέου model όταν τα προηγούμενα δεν επαρκούν.

Για τη διπλωματική, οι τρεις αυτές κατηγορίες πρέπει να διαχωρίζονται πειραματικά. Ένας agent που ανακαλεί γνωστό context δεν αποδεικνύει necessarily zero-shot adaptation σε άγνωστη αλλαγή. Αντίστοιχα, η γρήγορη recovery σε repeated layout πρέπει να αναφέρεται ως reuse ή retention benefit.

## Περιορισμοί και απειλές εγκυρότητας

Η μέθοδος είναι χειροποίητη, tabular και εξαρτάται από spatial hierarchy προσαρμοσμένη σε GridWorld. Οι environments έχουν ίδιο goal και παρόμοια state/action structure. Το planning θεωρεί κυρίως deterministic dynamics. Οι hyperparameters ρυθμίστηκαν εμπειρικά στα mazes A και B και δεν έγινε sensitivity analysis. Η σύγκριση δεν περιλαμβάνει σύγχρονες continual/meta-RL ή deep baselines.

Η hierarchical policy μπορεί να είναι suboptimal στο original fine-grained MDP. Η model library κλιμακώνεται άσχημα όταν οι αλλαγές είναι πολλές και μοναδικές. Η model selection μπορεί να αποτύχει λόγω τυχαίων αρχικών transitions και να δημιουργήσει duplicates. Επομένως, η πηγή δεν πρέπει να χρησιμοποιηθεί για να υποστηρίξει ότι context switching είναι καθολικά καλύτερο, αλλά για να σχεδιαστούν repeated-context tests, retention metrics και ισχυρά baselines.

## Χρήση στη διπλωματική

- **Προτεινόμενα κεφάλαια:** σχετικές εργασίες, GridWorld justification, non-stationarity, agent architectures, experimental scenarios και metrics.
- **Ισχυρισμοί που μπορεί να υποστηρίξει:** repeated context changes απαιτούν retention/recall metrics· stale models μπορούν να επιβραδύνουν adaptation· GridWorld επιτρέπει ελεγχόμενη αλλαγή routes/rules.
- **Πειραματική συνέπεια:** να υπάρχουν τουλάχιστον novel-change και recurring-change sequences. Να καταγράφονται detection delay, return drop, recovery time, relearning cost και performance στη δεύτερη εμφάνιση ίδιου context.
- **Τι δεν πρέπει να ισχυριστούμε:** ότι GridWorld είναι μέρος του επίσημου τίτλου, ότι hierarchical abstraction είναι αναγκαία, ή ότι recall παλιού model ισοδυναμεί με general adaptation.

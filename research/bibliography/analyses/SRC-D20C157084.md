G. A. Rummery and M. Niranjan, **On-line Q-learning using connectionist systems**, Cambridge University Engineering Department Technical Report CUED/F-INFENG/TR 166, 1994.

- **Verified here:** title, authors, year, report number, institutional provenance, and broad abstract-level scope through bibliographic/institutional mirrors.

## Why the source is retained

The report is historically associated with the development of online TD control variants later discussed in the SARSA lineage. It is useful to prevent the theoretical background from implying that SARSA first appeared only in later textbook terminology.

However, the report's own title and abstract-level descriptions concern connectionist/function-approximation systems and multiple Q/TD variants. The thesis comparator is a deterministic tabular SARSA implementation under a strict information boundary. Therefore this record should not be used to infer detailed properties of the thesis implementation without checking the report itself and the canonical modern SARSA description in Sutton & Barto.

## Safe current use

Until the original is checked, this source may support only bibliographic/historical statements such as:

- Rummery and Niranjan published the 1994 Cambridge technical report with this title and report identifier;

For the actual SARSA update rule, on-policy/off-policy contrast, behavior-policy semantics and thesis implementation rationale, use the already verified `SRC-701E163AC8` Sutton & Barto analysis/evidence.

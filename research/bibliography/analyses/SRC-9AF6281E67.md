# Policy-Conditioned Uncertainty Sets for Robust Markov Decision Processes

## Βιβλιογραφική ταυτότητα
Andrea Tirinzoni, Xiangli Chen, Marek Petrik, Brian D. Ziebart. Advances in Neural Information Processing Systems 32, 2018.

## Σκοπός και ερευνητικό ερώτημα
Εξετάζει πώς μπορούν να κατασκευαστούν uncertainty sets για robust MDPs από περιορισμένα trajectories μίας υποβέλτιστης reference policy χωρίς την υπερβολική συντηρητικότητα των ανεξάρτητων rectangular constraints.

## Σύνοψη
Η εργασία προτείνει policy-conditioned, non-rectangular uncertainty sets με constraints πάνω σε trajectory-level state-action features/marginal moments. Με αυτόν τον τρόπο, πληροφορία από περιορισμένα trajectories μπορεί να γενικεύσει μεταξύ καταστάσεων, αντί κάθε state-action pair να αντιμετωπίζεται ανεξάρτητα ως worst case.

## Μεθοδολογία
- finite-horizon robust decision processes,
- trajectories από reference/off-policy controller,
- feature expectations ως constraints στο ambiguity set,
- non-rectangular robust optimization,
- augmented-state/mixed-process solution,
- empirical comparison με rectangular robust control.

## Κύρια ευρήματα
1. Rectangular uncertainty sets μπορούν να είναι υπερβολικά conservative όταν τα δεδομένα είναι περιορισμένα.
2. Trajectory-level feature constraints επιτρέπουν coupling και generalization μεταξύ state-action regions.
3. Η επιλογή features αποτελεί ουσιώδη prior/modeling απόφαση και επηρεάζει δραστικά την uncertainty representation.
4. Η μέθοδος μεταφέρει πληροφορία από reference-policy trajectories αλλά δεν είναι online context detector ή post-change learner.

## Υποθέσεις και ορισμοί
Το uncertainty set περιορίζεται από feature statistics που συλλέγονται υπό reference policy. Η robustness εξακολουθεί να είναι worst-case optimization μέσα σε ένα κατασκευασμένο set και όχι ανίχνευση νέου regime.

## Περιορισμοί και απειλές εγκυρότητας
- feature engineering και reference-policy dependence,
- non-rectangular computation είναι πιο σύνθετο,
- finite-horizon formulation,
- limited-data robust control και όχι repeated environmental shifts,
- πιθανότητα mismatch όταν τα επιλεγμένα features δεν εκφράζουν τις πραγματικές dependencies.

## Χρήση στη διπλωματική
Υποστηρικτική πηγή για το robust-baseline design. Το protocol πρέπει να δηλώνει:
- rectangular ή non-rectangular uncertainty structure,
- features που ορίζουν global constraints,
- reference policy/data source,
- data budget,
- nominal και worst-case performance,
- compute overhead.

Δεν προτείνεται ως βασικός agent· χρησιμοποιείται για να αιτιολογήσει sensitivity/ablation του uncertainty-set design.

## Απαιτούμενα αποσπάσματα
1. Rectangular uncertainty sets μπορεί να προκαλέσουν υπερβολική συντηρητικότητα.
2. Trajectory-level features μπορούν να συνδέσουν uncertainty μεταξύ state-action regions.
3. Η uncertainty-set construction είναι prior/modeling choice και πρέπει να αναφέρεται ρητά.
4. Η μέθοδος δεν είναι online adaptation mechanism.

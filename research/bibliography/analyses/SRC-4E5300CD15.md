# Online Robust Planning Under Model Uncertainty: A Sample-Based Approach

## Βιβλιογραφική ταυτότητα

- **Συγγραφείς:** Tamir Shazman, Idan Lev-Yehudi, Ron Benchetrit, Vadim Indelman
- **Έτος:** 2026
- **Τύπος πηγής:** πρωτογενής θεωρητική και εμπειρική εργασία για robust online planning
- **Έκδοση:** AAAI-26
- **Πρωτότυπο που ελέγχθηκε:** πλήρες conference κείμενο στο `πηγές/SRC-4E5300CD15.md`

## Σκοπός και ερευνητικό ερώτημα

Η εργασία εξετάζει αν μπορεί να γίνει sample-based online planning όταν ο διαθέσιμος generative model είναι προσεγγιστικός και οι transition dynamics μπορεί να διαφέρουν από τις πραγματικές. Στόχος είναι να υπολογίζεται action online, μόνο από simulations του τρέχοντος state, με worst-case προστασία απέναντι σε bounded model misspecification και με finite-sample guarantees.

## Σύνοψη

Οι συγγραφείς προτείνουν το Robust Sparse Sampling (RSS), επέκταση του Sparse Sampling σε robust MDPs. Το RSS χρησιμοποιεί uncertainty sets γύρω από τον προσεγγιστικό transition kernel, robust Bellman backups και Sample Average Approximation για να προσεγγίζει το robust value από finite samples. Η θεωρία δίνει finite-time error bounds και complexity ανεξάρτητη από το πλήθος των states, αλλά εξαρτώμενη από planning depth, action branching, sample width και robust optimization.

Η εμπειρική αξιολόγηση γίνεται σε FrozenLake και CartPole με σκόπιμη απόκλιση ανάμεσα στον planning model και στις πραγματικές dynamics. Τα αποτελέσματα δείχνουν το κλασικό robustness trade-off: σε χαμηλή αβεβαιότητα το nominal Sparse Sampling μπορεί να αποδίδει καλύτερα, ενώ όσο αυξάνεται το model error το RSS διατηρεί πιο σταθερή επίδοση και μειώνει failures.

## Μοντέλο και υποθέσεις

- **MDP:** πιθανώς infinite/continuous state space και finite action space.
- **Model access:** προσεγγιστικός generative transition model `P^o` που μπορεί να δειγματίζει successor states.
- **Uncertainty set:** state–action rectangular set με Total Variation radius `ρ` γύρω από το `P^o`.
- **Robust objective:** μεγιστοποίηση του worst-case expected return μέσα στο uncertainty set.
- **Fail-state assumption:** υπάρχει absorbing zero-reward state, ώστε να απλοποιηθεί η dual robust action-value formulation.
- **Planning:** finite depth `H`, sample width `C`, online search tree και robust backups.
- **Knowledge requirement:** το uncertainty budget `ρ` θεωρείται διαθέσιμο ή εκτιμήσιμο.

## Θεωρητικά ευρήματα

1. **Finite-sample robust planning:** το RSS προσεγγίζει την optimal robust value function με error bound που μπορεί να μειωθεί αυξάνοντας planning depth και sample budget.
2. **State-space independence:** η αναλυτική complexity δεν εξαρτάται άμεσα από το cardinality του state space, χαρακτηριστικό σημαντικό για continuous ή πολύ μεγάλους χώρους.
3. **Υπάρχει πρόσθετο robust-optimization overhead:** σε σχέση με το Sparse Sampling εμφανίζεται επιπλέον logarithmic factor, ενώ το συνολικό tree-search cost εξακολουθεί να αυξάνει έντονα με horizon και branching.
4. **Οι guarantees είναι guarantees robustness, όχι adaptation.** Το RSS δεν μαθαίνει ότι συνέβη changepoint ούτε ενημερώνει policy/history ανά regime. Σχεδιάζει online με ένα δεδομένο uncertainty set.

## Εμπειρική αξιολόγηση

### FrozenLake

- 8×8 stochastic grid.
- Model error μόνο σε states γειτονικά σε holes.
- Planning horizon `H=3`, sample width `C=50`, `γ=0.99`.
- `ρ` από 0.1 έως 0.6.
- 1000 seeds και standard errors.
- Το RSS υπερέχει του nominal SS για όλα τα αναφερόμενα `ρ`, με αυξανόμενη διαφορά όσο μεγαλώνει η αβεβαιότητα, αλλά και τα δύο υστερούν από SS με πρόσβαση στις πραγματικές dynamics.

### CartPole

Η αβεβαιότητα εισάγεται στις dynamics/noise του μοντέλου. Σε χαμηλό noise το robust planning μπορεί να είναι υπερβολικά συντηρητικό και να υστερεί από nominal planning. Σε υψηλότερο misspecification το RSS διατηρεί πιο σταθερό return/success και τελικά υπερέχει, αναδεικνύοντας το robustness–nominal-performance crossover.

## Σχέση με τη διπλωματική

Η πηγή είναι ιδιαίτερα χρήσιμη για να οριοθετήσει μία model-based robust baseline στο GridWorld:

- robust planning όταν υπάρχει simulator/model,
- known bounded transition-model error,
- χωριστή αναφορά nominal utility και disturbed performance,
- failure-rate ή hazard metrics πέρα από average return.

Δεν αποτελεί άμεση λύση για repeated unknown environmental changes. Συμπληρώνει το `SRC-0AEF7EF16A` και τις robust-MDP πηγές, αλλά διαφέρει από detector/reset, recency learning και context recall.

## Πρακτική μετάφραση στο protocol

- `uncertainty_radius_known`: yes/no/estimated,
- `generative_model_available`: yes/no,
- `robust_backup_scope`: all states / uncertain states only,
- clean return και disturbed return,
- failure/hazard rate,
- planning samples ανά action,
- planning depth,
- per-decision compute time,
- conservativeness gap σε low-noise settings,
- model-misspecification severity χωριστά από temporal changepoint severity.

## Περιορισμοί και απειλές εγκυρότητας

Η μέθοδος απαιτεί generative model, uncertainty radius και rectangular uncertainty structure. Η fail-state assumption δεν ισχύει αυτούσια σε κάθε MDP. Τα experiments είναι δύο benchmarks και όχι repeated non-stationary sequences. Η selective εφαρμογή robust backups σε uncertain regions προϋποθέτει ότι είναι γνωστό πού βρίσκεται η αβεβαιότητα. Η state-space-independent θεωρία δεν σημαίνει χαμηλό συνολικό κόστος, επειδή το lookahead tree εξαρτάται εκθετικά από depth και action branching.

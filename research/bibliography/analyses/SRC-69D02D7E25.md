# Time Limits in Reinforcement Learning

## Βιβλιογραφική ταυτότητα

- **Συγγραφείς:** Fabio Pardo, Arash Tavakoli, Vitaly Levdik, Petar Kormushev
- **Έτος:** 2018
- **Τύπος:** peer-reviewed πρωτογενής μεθοδολογική/εμπειρική εργασία RL
- **Δημοσίευση:** Proceedings of the 35th International Conference on Machine Learning, PMLR 80:4045–4054

## Σκοπός και συνάφεια

Η εργασία διαχωρίζει δύο διαφορετικές έννοιες που συχνά υλοποιούνται με το ίδιο episode time limit: (α) ένα πραγματικά finite-horizon task, όπου η διάρκεια αποτελεί μέρος του objective, και (β) ένα continuing/indefinite task όπου το time limit είναι τεχνικός μηχανισμός reset/training και δεν αποτελεί terminal state του MDP. Η διάκριση είναι άμεσα κρίσιμη για το protocol-v2 επειδή το GridWorld έχει `max_steps` και οι value-based learners πρέπει να γνωρίζουν αν η λήξη αυτή είναι termination ή truncation.

## Κύρια σημεία που υποστηρίζονται άμεσα

1. **Finite-horizon time limit:** όταν το fixed horizon είναι μέρος του task, η πληροφορία για τον εναπομένοντα χρόνο πρέπει να περιλαμβάνεται στην agent input/state ώστε να μην παραβιάζεται η Markov property.
2. **Administrative/training time limit:** όταν το time limit δεν αποτελεί μέρος του underlying task, η μετάβαση στο cutoff δεν πρέπει να αντιμετωπίζεται ως πραγματικό terminal state· η value estimate πρέπει να bootstrap από την κατάσταση στο τέλος του partial episode.
3. **Λανθασμένος χειρισμός time limits μπορεί να βλάψει τη μάθηση.** Οι συγγραφείς συνδέουν τον μη ορθό χειρισμό με state aliasing, invalidation of experience replay, suboptimal policies και training instability.
4. **Η επιλογή semantics προηγείται της υλοποίησης.** Δεν αρκεί να υπάρχει ένα `done` flag· πρέπει να δηλωθεί αν η λήξη προέρχεται από το task ή από εξωτερικό time limit.

## Εφαρμογή στο protocol-v2

Η διπλωματική ορίζει το `max_steps` ως **administrative truncation**: ο στόχος του navigation task δεν είναι «μεγιστοποίησε reward μέχρι ένα κρυφό fixed countdown», αλλά η επίτευξη του goal υπό ελεγχόμενη uncertainty, με episode cutoff για bounded execution. Συνεπώς:

- goal arrival = πραγματικό termination;
- `max_steps` cutoff = truncation;
- value-based learners bootstrap through truncation;
- remaining time δεν προστίθεται στην controlled position observation·
- αν ένα campaign interaction budget λήξει mid-episode, αυτό είναι measurement stop και όχι fabricated terminal MDP transition.

Η πηγή επίσης τεκμηριώνει ένα **ιστορικό limitation**: τα v1.0/v1.1 tabular paths χρησιμοποιούσαν `bootstrap_on_truncation=False` χωρίς remaining-time observation. Τα frozen historical results δεν αλλάζουν ή ακυρώνονται· το limitation δηλώνεται και δεν μεταφέρεται στο v2.

## Περιορισμοί

Η εργασία δεν επιλέγει το κατάλληλο `max_steps` για το thesis GridWorld, δεν καθορίζει reward values και δεν ορίζει το τελικό interaction budget. Η εφαρμογή της στο project εξαρτάται από τη ρητή δική μας επιλογή ότι το timeout είναι administrative rather than task-defining. Δεν πρέπει να χρησιμοποιηθεί για να ισχυριστούμε ότι κάθε episodic RL task είναι continuing.

## Χρήση στη διπλωματική

- **Κεφάλαια:** Μεθοδολογία, πειραματικό πρωτόκολλο, implementation validity, threats to validity.
- **Ρόλος:** κύρια μεθοδολογική πηγή για termination/truncation semantics.
- **Ισχυρισμοί:** διάκριση finite-horizon από administrative time limit, time-awareness στο πρώτο case, bootstrapping στο δεύτερο.
- **Μη ισχυρισμοί:** συγκεκριμένο horizon/root count ή superiority οποιουδήποτε algorithm.

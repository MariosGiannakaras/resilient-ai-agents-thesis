# Meta-Gradients in Non-Stationary Environments

## Βιβλιογραφική ταυτότητα

- **Συγγραφείς:** Jelena Luketina, Sebastian Flennerhag, Yannick Schroecker, David Abel, Tom Zahavy, Satinder Singh
- **Έτος:** 2022
- **Τύπος πηγής:** πρωτογενής πειραματική εργασία συνεδρίου
- **Δημοσίευση:** 1st Conference on Lifelong Learning Agents, PMLR 199
- **Πρωτότυπο που ελέγχθηκε:** `πρωτότυπα/SRC-153C917DE1.pdf`
- **Κύριο αντικείμενο:** contextual white-box meta-gradients για adaptive hyperparameters σε non-stationary RL

## Σκοπός και ερευνητικό ερώτημα

Η εργασία μελετά αν meta-gradient methods μπορούν να προσαρμόζουν online hyperparameters, όπως entropy coefficient ή epsilon exploration rate, όταν το περιβάλλον αλλάζει. Εξετάζει τρία ερωτήματα: πόσο context πρέπει να λαμβάνει ο meta-optimizer, ποια meta-parameter schedules μαθαίνει και αν το όφελος αυξάνεται όταν η non-stationarity γίνεται εντονότερη.

Η κεντρική υπόθεση είναι ότι ένα fixed hyperparameter schedule δεν είναι κατάλληλο για ολόκληρη τη ζωή του agent. Μετά από task switch μπορεί να απαιτείται αυξημένη εξερεύνηση, ενώ μετά την επαναμάθηση πρέπει να μειώνεται. Τα standard white-box meta-gradients είναι σχεδόν memoryless και αντιδρούν μόνο στην τοπική επίδραση των hyperparameters. Οι contextual meta-gradients αντικαθιστούν τη σταθερή meta-parameter τιμή με learned function επιλεγμένων context features, όπως reward history, TD error, value estimates και state visitation.

Η πηγή είναι ιδιαίτερα συναφής με την αίτηση επειδή αξιολογεί μεταβαλλόμενους κανόνες ανταμοιβής και transition functions σε απλά GridWorlds. Δεν αποδεικνύει όμως ότι meta-gradients είναι η καταλληλότερη τελική λύση για τη διπλωματική· παρέχει κυρίως evidence για adaptive exploration, change-rate experiments και context-feature design.

## Σύνοψη

Οι συγγραφείς περιορίζονται σε white-box meta-gradients: η βασική update rule παραμένει γνωστή και ο meta-learner προσαρμόζει επιλεγμένα hyperparameters. Στην contextual εκδοχή, μια learned function λαμβάνει low-dimensional statistics της πρόσφατης συμπεριφοράς και παράγει νέα τιμή exploration ή regularization parameter. Η ιδέα είναι ότι η πτώση reward ή η αύξηση TD error μετά από αλλαγή μπορεί να λειτουργήσει ως σήμα για μεγαλύτερη plasticity.

Δύο controlled non-stationary environments χρησιμοποιούνται. Στο Two Colors, ένας agent σε 5×5 GridWorld πρέπει να επιλέγει μεταξύ δύο αντικειμένων και το ποιο δίνει +1 ή −1 αλλάζει περιοδικά. Στα Switching MDPs, ο agent μεταφέρεται περιοδικά μεταξύ διαφορετικών grid worlds των οποίων rewards, walls και transitions έχουν δημιουργηθεί τυχαία. Η παραλλαγή με 4 MDPs επιτρέπει επαναλαμβανόμενη εμπειρία και transfer, ενώ η παραλλαγή με 1000 MDPs προσεγγίζει συνεχώς νέα tasks.

## Μεθοδολογία

- **Agents:** Actor-Critic και Q(λ).
- **Meta-gradient οικογένειες:** standard meta-gradients και Bootstrapped Meta-Gradients (BMG), με ή χωρίς contextual features.
- **Adaptive quantities:** entropy-loss coefficient για actor-critic και epsilon exploration για Q(λ), με ορισμένες επεκτάσεις σε επιπλέον coefficients.
- **Context features:** reward, value, TD error, action probabilities, gradient similarity, προηγούμενες meta-parameter predictions και state-visitation statistics.
- **Two Colors:** 5×5 GridWorld, memoryless agents, αλλαγή θετικού/αρνητικού αντικειμένου συνήθως κάθε 100.000 steps.
- **Switching MDPs:** νέα grid world task κάθε 100.000 steps, με random reward και transition/wall configuration· N=4 και N=1000 variants.
- **Non-stationarity rate:** μεταβολή του interval μεταξύ task switches.
- **Runs:** δέκα random seeds για τους κύριους πίνακες και figures.
- **Reporting:** mean και standard deviation σε κύρια tables, 95% confidence intervals σε schedules, και median/interquartile ranges στα appendix plots για change-rate comparisons.

## Κύρια ευρήματα

1. **Το performance context μπορεί να λειτουργήσει ως online adaptation signal.** Reward, TD error και value histories συσχετίζονται με task changes και επιτρέπουν στη meta-function να αυξάνει exploration μετά από performance drop. Τεκμηρίωση: σελ. 6–8 και 15, Sections 6.2–6.3 και Appendix A.5.

2. **Context-free meta-gradients δεν προσφέρουν σταθερό πλεονέκτημα σε έντονη non-stationarity.** Στα experiments, η contextual εκδοχή είναι πιο αξιόπιστη, ενώ χωρίς context το learned schedule συχνά γίνεται σχεδόν σταθερό ή δεν ξεπερνά consistent fixed baseline. Τεκμηρίωση: σελ. 5–9, Sections 6–7.

3. **Η ανάγκη context αυξάνεται όταν τα tasks είναι πολλά και δεν επαναλαμβάνονται.** Στα Switching MDPs με 1000 MDPs, reward/rich context δίνει μεγαλύτερη βελτίωση από ό,τι στη variant με 4 επαναλαμβανόμενα MDPs. Τεκμηρίωση: σελ. 5–6, Table 2 και Section 6.1.

4. **Περισσότερο context δεν είναι μονοτονικά καλύτερο.** Η σταδιακή προσθήκη features συνήθως βελτιώνει την επίδοση, αλλά υπάρχουν εξαιρέσεις. Η ποιότητα και η συνάφεια των features είναι σημαντικότερη από την απλή dimensionality. Τεκμηρίωση: σελ. 7–8, Figure 3 και Appendix A.5.

5. **Υπάρχει όριο στον ρυθμό αλλαγής που μπορεί να παρακολουθήσει ο agent.** Στο Two Colors, οι rich-context meta-gradients έχουν ευρύτερη περιοχή πλεονεκτήματος, αλλά όταν το task switch γίνεται πολύ συχνό οι μέθοδοι αποτυγχάνουν να ξεπεράσουν το fixed baseline. Η Figure 5 αναφέρει αποτυχία στα 25k steps, ενώ το κείμενο περιγράφει deterioration περίπου στα 50k· οι τιμές είναι domain-specific και δεν πρέπει να παρουσιαστούν ως γενικό threshold. Τεκμηρίωση: σελ. 8–9 και 15–16, Section 6.4 και Figures 5, 8–9.

6. **Η επαναληψιμότητα του context distribution είναι κρυφή υπόθεση.** Τα reward-related features παραμένουν σε ελεγχόμενο range στα συγκεκριμένα environments, πράγμα που διευκολύνει τη generalization της meta-function. Οι authors προτείνουν μελλοντικό έλεγχο σε environments με λιγότερο repeatable contexts. Τεκμηρίωση: σελ. 9 και 12, Conclusion και Appendix A.2.

## Υποθέσεις και ορισμοί

Η μέθοδος θεωρεί ότι τα context features μπορούν να συνοψίσουν πληροφορία σχετική με την κατάλληλη hyperparameter schedule. Δεν γίνεται gradient propagation μέσω των context features. Η non-stationarity στα κύρια experiments είναι discrete, regular και ελεγχόμενη, ώστε ο ρυθμός αλλαγής να μεταβάλλεται συστηματικά και οι learned schedules να είναι ερμηνεύσιμες.

Στο Two Colors, η αλλαγή reward identity απαιτεί re-exploration. Στα Switching MDPs αλλάζουν reward και transition structure, αλλά δύο tasks μπορεί να είναι παρόμοια και να επιτρέπουν transfer. Αυτή η διάκριση δείχνει ότι η βέλτιστη post-change exploration δεν είναι πάντα «όσο περισσότερη τόσο καλύτερη».

## Περιορισμοί και απειλές εγκυρότητας

Τα environments είναι μικρά και οι αλλαγές συμβαίνουν σε γνωστά regular intervals. Αυτό ευνοεί context functions που μαθαίνουν επαναλαμβανόμενο pattern και δεν καλύπτει arbitrary timing ή noisy false alarms. Οι context features επιλέγονται χειροκίνητα και η αποτελεσματικότητά τους εξαρτάται από task-specific συσχετίσεις.

Οι κύριες συγκρίσεις βασίζονται σε best hyperparameter configurations, άρα το tuning protocol και το budget πρέπει να λαμβάνονται υπόψη. Τα αποτελέσματα από 10 seeds είναι ισχυρότερα από τις συνήθεις few-run μελέτες, αλλά η εργασία αναφέρει πολλές configurations και δεν μετατρέπει κάθε σύγκριση σε καθολικό statistical claim.

Η computational complexity των meta-gradients, η ανάγκη outer-loop optimization και η ευαισθησία σε rollout/meta-rollout settings μπορεί να είναι δυσανάλογη για μια διπλωματική που επιδιώκει μικρό και επαληθεύσιμο ερευνητικό πυρήνα. Επομένως η πηγή δεν αρκεί για να επιλεγεί meta-gradient agent χωρίς pilot feasibility test.

## Χρήση στη διπλωματική

Η πηγή πρέπει να χρησιμοποιηθεί ως υποστηρικτική αναφορά για:

- adaptive exploration μετά από performance drop,
- reward/TD-error/value ως υποψήφια change/context signals,
- controlled GridWorlds με reward και transition switching,
- το change interval ως ανεξάρτητο experimental factor,
- την ανάγκη baseline με fixed hyperparameters,
- την ύπαρξη adaptation-rate limit και unrecoverable regimes,
- τη διάκριση επαναλαμβανόμενων tasks από σχεδόν πάντα νέα tasks.

Μπορεί να αιτιολογήσει έναν απλούστερο adaptive-epsilon agent ή context-aware scheduler, χωρίς να απαιτεί πλήρη meta-gradient implementation. Εάν επιλεγεί πλήρης meta-gradient μέθοδος, πρέπει να δικαιολογηθεί computational budget, tuning fairness και πρόσθετη πολυπλοκότητα.

## Επιτρεπτοί και μη επιτρεπτοί ισχυρισμοί

**Επιτρέπεται να υποστηριχθεί ότι:**

- context features που αντανακλούν performance drop μπορούν να βοηθήσουν adaptive exploration στα συγκεκριμένα non-stationary GridWorlds,
- context-free meta-gradients δεν παρουσιάζουν σταθερό πλεονέκτημα σε υψηλή non-stationarity,
- ο ρυθμός αλλαγής και η ποικιλία tasks επηρεάζουν την ικανότητα adaptation,
- μικρά GridWorlds είναι χρήσιμα για controlled isolation reward και transition shifts.

**Δεν επιτρέπεται να υποστηριχθεί ότι:**

- contextual meta-gradients είναι καθολικά καλύτερα από κάθε fixed ή adaptive μέθοδο,
- οι thresholds 25k ή 50k steps μεταφέρονται σε άλλο environment,
- περισσότερα context features εγγυώνται καλύτερη απόδοση,
- η εργασία καλύπτει άγνωστο timing, stochastic action failures ή unstructured adversarial changes χωρίς πρόσθετη αξιολόγηση.

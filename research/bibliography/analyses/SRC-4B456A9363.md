# Non-stationary Reinforcement Learning under General Function Approximation

## Βιβλιογραφική ταυτότητα

- **Συγγραφείς:** Songtao Feng, Ming Yin, Ruiquan Huang, Yu-Xiang Wang, Jing Yang, Yingbin Liang
- **Έτος:** 2023
- **Τύπος πηγής:** πρωτογενής θεωρητική εργασία για non-stationary RL με general function approximation
- **DOI / PMLR / URL:** Proceedings of Machine Learning Research 202, ICML 2023 — https://proceedings.mlr.press/v202/feng23e.html
- **Πρωτότυπο που ελέγχθηκε:** `πρωτότυπα/SRC-4B456A9363.pdf`

## Σκοπός και ερευνητικό ερώτημα

Η εργασία εξετάζει αν μπορεί να σχεδιαστεί provably efficient model-free algorithm για non-stationary MDPs χωρίς να περιορίζεται σε tabular ή γραμμική function approximation. Το κεντρικό ερώτημα είναι πώς μπορεί μια sliding-window μέθοδος να απομονώνει πρόσφατα δεδομένα, να ελέγχει το distribution mismatch και να επιτυγχάνει bounded dynamic regret.

## Σύνοψη

Οι συγγραφείς εισάγουν τη Dynamic Bellman Eluder (DBE) dimension ως complexity measure για non-stationary MDPs και προτείνουν τον SW-OPEA, έναν confidence-set based algorithm που χρησιμοποιεί sliding window και local variation budget. Η windowed confidence region κατασκευάζεται έτσι ώστε να περιλαμβάνει την optimal value function του τρέχοντος episode παρά τη μεταβολή transitions και rewards μέσα στο πρόσφατο παράθυρο.

Η εργασία παρέχει dynamic-regret upper bounds και θεωρητικές συγκρίσεις με UCB-type algorithms σε linear και tabular ειδικές περιπτώσεις. Η πρακτική αξία για τη διπλωματική δεν είναι η άμεση υλοποίηση του SW-OPEA, αλλά η ισχυρή θεωρητική βάση για recent-data mechanisms: τα παλιά δεδομένα προκαλούν bias όταν το περιβάλλον αλλάζει, ενώ πολύ μικρό window αυξάνει uncertainty και sample cost.

## Μεθοδολογία

- **Πρόβλημα:** episodic MDP με time-varying transition kernels και reward functions.
- **Μοντέλο:** general function classes για candidate Q-functions και Bellman residuals.
- **Υποθέσεις:** realizability, generalized completeness και πεπερασμένη/ελεγχόμενη DBE dimension.
- **Αλγόριθμος:** SW-OPEA, confidence-set optimization με sliding window μήκους `w` και local variation correction.
- **Μετρική:** dynamic regret έναντι της optimal policy κάθε episode.
- **Ανάλυση:** upper bounds σε όρους window size, DBE dimension, horizon και reward/transition variation.
- **Εμπειρική διαδικασία:** δεν παρουσιάζεται πλήρης empirical benchmark· οι συγκρίσεις είναι θεωρητικές και μέσω special-case bounds.

## Κύρια ευρήματα

1. **Η recent-memory λογική είναι θεμελιωμένη σε distribution mismatch.** Το confidence set χρησιμοποιεί μόνο πρόσφατα episodes και διορθώνει ρητά για local variation, ώστε stale data να μην αντιμετωπίζονται ως samples από το τρέχον MDP. Τεκμηρίωση: Introduction και algorithm contribution, PDF σελ. 1–2.
2. **Το window size είναι bias–variance trade-off.** Μεγάλο παράθυρο αυξάνει την έκθεση σε παλιά regimes, ενώ μικρό παράθυρο μειώνει samples και αυξάνει estimation uncertainty. Το θεωρητικό bound βελτιστοποιεί το `w` σε σχέση με average variation. Τεκμηρίωση: Theorem 5.2 και Corollary 5.3, PDF σελ. 5–7.
3. **Το dynamic regret διαχωρίζει stationary learning cost και non-stationarity cost.** Το bound περιλαμβάνει όρο που ανάγεται στο static MDP και πρόσθετους όρους από reward/transition variation. Τεκμηρίωση: discussion μετά το Corollary 5.3, PDF σελ. 6–7.
4. **Το πλεονέκτημα δεν είναι καθολικό.** Οι θεωρητικές συγκρίσεις δείχνουν καλύτερη εξάρτηση από ορισμένες διαστάσεις και το horizon, αλλά χειρότερη εξάρτηση από average transition variation· ο SW-OPEA είναι πιο ελκυστικός στο small-variation regime. Τεκμηρίωση: Sections 5–6, PDF σελ. 7–9.
5. **Sliding windows, restart και exponential weighting είναι συγγενείς αλλά διαφορετικές επιλογές.** Η related-work ανάλυση καταγράφει sliding-window tabular methods, restart schemes και exponentially weighted least squares ως διαφορετικούς τρόπους ελέγχου stale data. Τεκμηρίωση: Section 1.1, PDF σελ. 2–3.
6. **Η εργασία δεν παρέχει εμπειρική απόδειξη ότι συγκεκριμένο window θα είναι βέλτιστο στο δικό μας GridWorld.** Το `w` πρέπει να επιλεγεί με pilot ή nested validation χωρίς test leakage.

## Υποθέσεις και ορισμοί

Η DBE dimension γενικεύει complexity notions για Bellman function classes σε time-varying MDPs. Η dynamic regret συγκρίνει την policy του agent σε κάθε episode με την optimal policy του αντίστοιχου τρέχοντος MDP.

Για τη διπλωματική, η πηγή μεταφράζεται σε απλούστερο protocol:

- recent-window ή exponential-recency weighting,
- ρητό `effective_memory_length`,
- καταγραφή ηλικίας samples/updates,
- ξεχωριστή tuning διαδικασία για window/discount factor,
- κοινή αναφορά recovery και nominal cost.

## Περιορισμοί και απειλές εγκυρότητας

Οι guarantees βασίζονται σε realizability/completeness και ελεγχόμενη complexity της function class. Η ανάλυση απαιτεί γνώση ή έλεγχο variation quantities για βέλτιστη επιλογή window. Δεν υπάρχει άμεση empirical σύγκριση σε GridWorld και ο SW-OPEA είναι πολύ πιο σύνθετος από τις ανάγκες μιας resource-aware tabular διπλωματικής. Οι theoretical regret comparisons δεν πρέπει να μετατραπούν σε empirical superiority claims.

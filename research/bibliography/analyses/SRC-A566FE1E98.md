# SRC-A566FE1E98 — google-research/rliable

## Περιεχόμενο

Archived GitHub repository της βιβλιοθήκης `rliable`, με implementations για stratified bootstrap confidence intervals, IQM, optimality gap, probability of improvement και performance profiles.

## Αξιολόγηση

Η βιβλιοθήκη είναι άμεσα χρήσιμη για την υλοποίηση της στατιστικής ανάλυσης. Ωστόσο, το README δεν αποτελεί ανεξάρτητο scientific evidence. Η θεωρητική και εμπειρική τεκμηρίωση των metrics έχει ήδη επιλεγεί μέσω του accompanying NeurIPS paper `SRC-0A4AFAC8E9`.

Επιπλέον, το repository έχει αρχειοθετηθεί και πρέπει να γίνει pin συγκεκριμένης έκδοσης/commit εάν χρησιμοποιηθεί.

## Απόφαση

**Απόρριψη ως επιστημονική πηγή, διατήρηση ως implementation dependency.** Στη διπλωματική θα παρατίθεται το paper για claims και θα καταγράφεται η ακριβής software version για reproducibility.

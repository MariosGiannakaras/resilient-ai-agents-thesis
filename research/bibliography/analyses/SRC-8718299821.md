# Safe Reinforcement Learning via Shielding

## Βιβλιογραφική ταυτότητα
Mohammed Alshiekh, Roderick Bloem, Rüdiger Ehlers, Bettina Könighofer, Scott Niekum, Ufuk Topcu. 2018-era formal shielding work, arXiv:1708.08611.

## Σκοπός και ερευνητικό ερώτημα
Εισάγει runtime shield που επιβάλλει temporal-logic safety κατά την εκπαίδευση και execution του RL agent, είτε περιορίζοντας προκαταβολικά τις actions είτε διορθώνοντας unsafe action μετά την πρόταση του learner.

## Σύνοψη
Η εργασία διαχωρίζει καθαρά το learning objective από το correctness layer. Το shield υπολογίζεται από safety specification και abstraction του environment και σχεδιάζεται για minimum interference.

## Μεθοδολογία
- finite MDP/RL setting,
- temporal-logic safety specification,
- reactive shield synthesis,
- preemptive και post-posed shielding,
- convergence considerations,
- empirical scenarios.

## Κύρια ευρήματα
1. Runtime safety μπορεί να επιβληθεί εξωτερικά από τον learning algorithm.
2. Preemptive shield περιορίζει το action set, ενώ post-posed shield διορθώνει unsafe actions.
3. Minimum interference είναι ξεχωριστό design objective.
4. Shielded correctness δεν ισοδυναμεί με learned robustness/resilience της policy.

## Υποθέσεις και ορισμοί
Απαιτούνται formal safety specification και environment abstraction αρκετή για shield synthesis.

## Περιορισμοί και απειλές εγκυρότητας
- prior formal model/specification,
- shield performance εξαρτάται από abstraction validity,
- structural change μπορεί να ακυρώσει το shield,
- intervention μπορεί να αλλάξει την effective trajectory distribution,
- δεν αποτελεί changepoint detector ή adaptation mechanism.

## Σχέση με άλλες πηγές
Θεμελιώδης πρόγονος των runtime assurance/shield sources `SRC-23A2C07D09` και `SRC-B9911A6CFB`.

## Χρήση στη διπλωματική
Υποστηρικτική foundational πηγή. Εάν χρησιμοποιηθεί shielded baseline καταγράφονται:
- preemptive/post-posed mode,
- proposed action και executed action,
- intervention rate,
- minimum-interference violations/overrides,
- abstraction/specification version,
- shield revalidation latency μετά από structural change.

## Απαιτούμενα αποσπάσματα
1. Shielding διαχωρίζει runtime correctness από learning.
2. Preemptive και post-posed intervention έχουν διαφορετική semantics.
3. Minimum interference πρέπει να μετράται μαζί με safety.
4. Shield capability δεν αποτελεί learned resilience.

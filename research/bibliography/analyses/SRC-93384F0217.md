# SRC-93384F0217 — Diversity Is All You Need: Learning Skills without a Reward Function

## Συνεισφορά

Η DIAYN μαθαίνει unsupervised latent-conditioned skills μεγιστοποιώντας mutual information μεταξύ skill και visited states μαζί με maximum-entropy policy objective. Τα skills μπορούν να χρησιμοποιηθούν για exploration, initialization, hierarchy και imitation.

## Αξιολόγηση συνάφειας

Η εργασία είναι θεμελιώδης για unsupervised skill discovery, αλλά δεν απαντά άμεσα στην ερευνητική ερώτηση της διπλωματικής:

- δεν μελετά controlled environmental changepoints,
- δεν συγκρίνει continual update, reset, recency ή context recall,
- τα skills μαθαίνονται σε ξεχωριστή unsupervised pretraining phase,
- δεν παρέχονται detector false alarms, adaptation delay ή recovery curves,
- η πλήρης SAC/discriminator architecture είναι δυσανάλογη προς το tabular scope.

Η ανάγκη για diverse exploration καλύπτεται ήδη από state entropy, RND/count bonuses και context-policy sources χωρίς να εισαχθεί hierarchical skill library.

## Απόφαση

**Απόρριψη από το curated package λόγω scope και implementation complexity, όχι λόγω ποιότητας.** Μπορεί να επανεξεταστεί μόνο εάν η διπλωματική επεκταθεί ρητά σε unsupervised skill libraries.

# Efficient Adaptation of Reinforcement Learning Agents to Sudden Environmental Change

## Βιβλιογραφική ταυτότητα
Jonathan Clifford Balloch. *Efficient Adaptation of Reinforcement Learning Agents to Sudden Environmental Change*. PhD Dissertation, School of Interactive Computing, Georgia Institute of Technology, 2024. Advisor: Mark O. Riedl.

## Σκοπός και ερευνητικό ερώτημα
Η διατριβή εξετάζει πώς RL agents μπορούν να προσαρμόζονται αποδοτικά όταν το environment αλλάζει ξαφνικά μετά την αρχική εκπαίδευση. Το framing είναι πολύ κοντά στο πειραματικό αντικείμενο της παρούσας διπλωματικής: ο agent έχει μάθει policy σε `MDP_source`, εισάγεται novelty που δημιουργεί `MDP_target`, η performance συχνά καταρρέει προσωρινά και μετράται η ταχύτητα/ποιότητα της επαναπροσαρμογής.

Η εργασία συνδέει novelty, online test-time adaptation, exploration, model-based learning και interpretable world models, χωρίς να περιορίζεται σε ένα μόνο algorithm.

## Κύριες συνεισφορές
### 1. Novelty ontology και NovGrid
Η διατριβή οργανώνει διαφορετικούς τύπους novelty σε sequential decision-making problems και χρησιμοποιεί NovGrid/MiniGrid-style tasks όπου η novelty δεν είναι αναγκαστικά άμεσα observable. Παραδείγματα:
- Door/Key rule change: πριν λειτουργεί ένα κλειδί, μετά άλλο.
- Lava semantics change: πριν η lava είναι terminal/αρνητική, μετά γίνεται traversable/safe.

Αυτό είναι ιδιαίτερα χρήσιμο επειδή διαχωρίζει αλλαγή **semantics/dynamics** από απλή observation perturbation.

### 2. Explicit adaptation metrics
Η εργασία διαχωρίζει:
- **convergence efficiency** στο pre-novelty task,
- **adaptive efficiency** μετά τη novelty,
- **final adaptive performance**,
- **transfer area under the curve (Tr-AUC)**.

Η adaptive efficiency μετρά πόσα interaction steps χρειάζονται από την έναρξη του novel task έως convergence στη νέα task. Η Tr-AUC συνοψίζει pre-transfer capability και τη learning curve μετά τη novelty.

Σημαντική methodological λεπτομέρεια: metrics που απαιτούν convergence υπολογίζονται μόνο στα runs που ικανοποιούν συγκεκριμένα convergence conditions. Άρα ο αριθμός/ποσοστό runs που πραγματικά converged πρέπει να αναφέρεται μαζί με conditional adaptation metrics.

### 3. Exploration characteristics για adaptation
Η διατριβή συγκρίνει πολλές exploration strategies και αποσυνθέτει την exploration σε χαρακτηριστικά όπως exploration principle και temporal locality. Στα συγκεκριμένα experiments δεν υπάρχει μία μέθοδος που κυριαρχεί καθολικά σε όλα τα novelty types.

Αυτό υποστηρίζει την thesis επιλογή να συγκρίνει exploration/recency mechanisms σε πολλαπλούς shift types αντί να θεωρεί μία exploration rule γενικά ανθεκτικότερη.

### 4. Model-based adaptation και replay sampling
Η εργασία αναπτύσσει Dual Objective Priority Sampling (DOPS) για Dreamer-like model-based RL. Η βασική ιδέα είναι ότι world model και actor/critic έχουν διαφορετικές informational ανάγκες από το replay buffer· μία ενιαία priority signal μπορεί να είναι suboptimal.

Για την παρούσα διπλωματική το σημαντικό γενικό συμπέρασμα είναι ότι **replay prioritization objective είναι μέρος της adaptation mechanism** και ότι stale/pre-change data μπορεί να έχει διαφορετική αξία για model learning έναντι policy optimization.

### 5. Neuro-symbolic novelty detection/adaptation
Η διατριβή περιλαμβάνει WorldCloner-style neuro-symbolic model-based RL με learned rules, novelty detection και imagination-based policy adaptation. Παρότι αυτό είναι πολύ βαρύτερο από το resource-aware baseline matrix, παρέχει conceptual evidence για:
- explicit novelty model,
- change-specific model update,
- internal simulation πριν από costly real interactions.

### 6. Concept Bottleneck World Models
Η τελευταία γραμμή εξετάζει concept bottlenecks για knowledge preservation και adaptation. Η αξία για το thesis είναι κυρίως ως threat-to-validity/representation note: representation structure μπορεί να επηρεάζει πόσο επαναχρησιμοποιήσιμη είναι η γνώση μετά από shift.

## Experimental protocol
Η διατριβή χρησιμοποιεί τόσο discrete όσο και continuous-control environments. Στο NovGrid DoorKeyChange experiment, ο agent μαθαίνει αρχικά stationary task και σε προκαθορισμένο interaction step εισάγεται novelty· έπειτα μετράται η recovery/adaptation curve.

Η evaluation περιλαμβάνει multiple seeds και uncertainty visualization. Για DOPS αναφέρονται πέντε trials/seeds σε ορισμένα experiments με bootstrap confidence intervals.

## Κρίσιμες μετρικές
### Adaptive efficiency
Αριθμός steps από την έναρξη του target/novel task μέχρι convergence. Lower is better.

### Final adaptive performance
Το τελικό reward/performance στο target task. Μπορεί να παραμένει κάτω από το pre-novelty performance, άρα η ταχύτητα adaptation και η τελική ποιότητα δεν πρέπει να συγχέονται.

### Transfer AUC
Συνοψίζει τη post-novelty learning curve, αλλά η ακριβής definition/filtering πρέπει να δηλώνεται.

### Convergence frequency
Επειδή adaptive-efficiency metrics μπορεί να είναι conditional on successful convergence, η πιθανότητα/συχνότητα convergence είναι ξεχωριστή outcome variable.

## Κύρια επιστημονικά συμπεράσματα για τη διπλωματική
1. **Recovery speed και final adapted quality είναι διαφορετικές διαστάσεις.**
2. **Conditional metrics μπορούν να κρύψουν failures.** Αν adaptive efficiency υπολογίζεται μόνο σε successful runs, χρειάζεται παράλληλα convergence/success fraction.
3. **Exploration strategy × novelty type interaction** πρέπει να εξετάζεται· μία strategy δεν είναι universal winner.
4. **Novelty semantics πρέπει να κατηγοριοποιείται**: transition/rule, reward/terminal semantics, geometry, observation, physical parameter κ.λπ.
5. **Replay-data value είναι objective-specific**: model learning και actor adaptation μπορεί να χρειάζονται διαφορετικό recency/priority treatment.
6. **Pre-novelty performance πρέπει να αναφέρεται** ώστε να ξεχωρίζει η αρχική competence από την adaptation ability.

## Περιορισμοί και απειλές εγκυρότητας
- Η διατριβή χρησιμοποιεί αρκετές deep/model-based μεθόδους που δεν είναι resource-comparable με tabular Q-learning.
- Ορισμένα metrics φιλτράρουν runs βάσει convergence, άρα απαιτείται προσοχή σε survivorship bias.
- Τα reported method rankings είναι benchmark-specific.
- Novelty injection είναι controlled και γνωστή στον evaluator· δεν σημαίνει ότι ο agent λαμβάνει oracle change signal.
- Ορισμένες method contributions είναι ενσωματωμένα dissertation chapters και δεν πρέπει να διπλομετρηθούν αν τα αντίστοιχα peer-reviewed papers προστεθούν αργότερα.

## Χρήση στη διπλωματική
**Κύρια πηγή.** Χρησιμοποιείται για:
- novelty taxonomy,
- abrupt source→target adaptation protocol,
- adaptive-efficiency metric,
- final adaptive performance,
- Tr-AUC/recovery-curve reasoning,
- convergence-frequency reporting,
- exploration × shift-type interactions,
- replay-priority/recency rationale.

Δεν απαιτείται υλοποίηση DOPS, WorldCloner ή Concept Bottleneck World Model. Οι μέθοδοι λειτουργούν κυρίως ως evidence για protocol design και mechanism ablations.

## Νέες protocol απαιτήσεις
- Report `adaptation_steps_to_threshold/convergence` μόνο μαζί με convergence fraction.
- Report final adapted return χωριστά από adaptation speed.
- Report post-change AUC/area-under-recovery curve για όλους τους runs, με σαφή handling των non-converged runs.
- Δηλώνεται pre-novelty performance και novelty injection point.
- Exploration ablations γίνονται σε περισσότερους από έναν shift types.
- Replay/recency policy δηλώνεται χωριστά για model-learning και policy-learning components όταν υπάρχει model-based agent.

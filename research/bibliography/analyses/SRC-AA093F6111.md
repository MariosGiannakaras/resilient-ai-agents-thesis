# Scientific analysis — SRC-AA093F6111

## Source
Lucas Schott et al., **Reward-Preserving Attacks For Robust Reinforcement Learning**, 2026 preliminary work.

## Assessment
The paper proposes adaptive adversarial attack magnitudes that preserve a controllable fraction of the nominal-to-worst-case return gap. It is an interesting contribution to adversarially robust RL and includes tabular and deep-RL reasoning about local criticality and task solvability.

The uncertainty model is nevertheless an **adversarial attacker** chosen for robust training, whereas the thesis core studies non-adversarial exogenous environmental changes and post-change adaptation. Adding the method would introduce a min-max attacker, uncertainty-set design, and deep robust-training machinery that are not required by the resource-aware baseline matrix.

The current curated set already contains primary robust-MDP and action/observation robustness sources sufficient to distinguish static/adversarial robustness from resilience.

## Decision
**Rejected from the curated thesis set because the attacker model is outside scope and the paper is preliminary; retained as archived evidence.**

# Resilient Multi-Agent Reinforcement Learning with Adversarial Value Decomposition

## Αξιολόγηση
Η εργασία προτείνει RADAR για cooperative MARL, εκπαιδεύοντας competing teams/antagonists ώστε να βελτιώνεται worst-case performance όταν agents αλλάζουν συμπεριφορά λόγω failures/updates.

## Όριο συνάφειας
Το disturbance model είναι agent-level/adversarial και το formal object είναι multi-agent value decomposition. Δεν αφορά single-agent exogenous transition/reward changepoints, detector-triggered adaptation ή resource-aware tabular recovery.

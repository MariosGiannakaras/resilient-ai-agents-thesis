# Επιστημονική ανάλυση — SRC-F622BE6812

## Βιβλιογραφική ταυτότητα

- **Τίτλος:** Exploration by Random Network Distillation
- **Συγγραφείς:** Yuri Burda, Harrison Edwards, Amos Storkey, Oleg Klimov
- **Δημοσίευση:** ICLR 2019
- **Προτεινόμενος ρόλος:** υποστηρικτική πηγή

## Ερευνητικό πρόβλημα

Η εργασία προτείνει scalable intrinsic-reward mechanism για sparse-reward exploration. Η novelty προσεγγίζεται από το prediction error ενός trainable predictor που προσπαθεί να μιμηθεί τα features ενός fixed randomly initialized target network.

## Μηχανισμός

- Το target network παραμένει σταθερό.
- Το predictor εκπαιδεύεται στις observations που έχει ήδη δει ο agent.
- Υψηλό prediction error χρησιμοποιείται ως intrinsic reward για δυνητικά novel observations.
- Intrinsic και extrinsic return διατηρούν χωριστά value heads και μπορούν να έχουν διαφορετικά discount/episodic properties.

## Κύρια ευρήματα

- Η RND βελτιώνει σημαντικά exploration σε hard-exploration Atari games.
- Το deterministic prediction target μειώνει το noisy-TV failure mode που εμφανίζεται σε stochastic forward-model prediction.
- Η prediction error επηρεάζεται όχι μόνο από visitation novelty αλλά και από optimization dynamics, capacity και normalization.
- Η intrinsic reward είναι μη στάσιμη: μειώνεται καθώς εκπαιδεύεται ο predictor.

## Σχέση με τη διπλωματική

Η RND δεν είναι change detector και δεν πρέπει να χρησιμοποιείται αυτούσια ως απόδειξη environmental shift. Είναι όμως χρήσιμη για:

- reactive exploration μετά από detector event,
- novelty score ως βοηθητικό diagnostic,
- σύγκριση random exploration με directed intrinsic exploration,
- τεκμηρίωση ότι prediction error δεν ισοδυναμεί αυτομάτως με calibrated epistemic uncertainty.

Σε tabular GridWorld η αρχή μπορεί να προσεγγιστεί πολύ απλούστερα με visitation counts ή prediction-error bonus, χωρίς deep RND implementation.

## Πειραματικές επιπτώσεις

Πρέπει να καταγράφονται:

- intrinsic και extrinsic reward χωριστά,
- normalization και reward scale,
- exploration budget μετά την αλλαγή,
- unique-state visitation και hazard exposure,
- recovery speed με και χωρίς intrinsic bonus,
- false novelty σε stochastic/noisy observations,
- predictor reset policy μετά από regime change.

## Περιορισμοί

- Τα κύρια experiments είναι Atari sparse-reward exploration, όχι non-stationary MDPs.
- Υψηλό prediction error δεν αποδεικνύει αλλαγή regime.
- Η predictor memory μπορεί να προκαλεί χαμηλό novelty score σε recurring regimes ή ψευδή novelty μετά από reset.
- Deep implementation έχει σημαντικά μεγαλύτερο compute από tabular baselines.

## Απόφαση

**Επαληθευμένη — εξαγωγή ναι, ως υποστηρικτική πηγή.** Χρησιμοποιείται για directed exploration και prediction-error caveats, όχι ως αυτόνομος resilience/change-detection algorithm.

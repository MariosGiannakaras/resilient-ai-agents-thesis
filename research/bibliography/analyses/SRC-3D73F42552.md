# Επιστημονική ανάλυση — SRC-3D73F42552

Primary full-text preprint that formulates reward hacking as max-min optimization over proxy rewards constrained by proxy–true reward correlation, with occupancy-measure estimation and experiments including a tomato-watering GridWorld.

This is a specification/reward-proxy uncertainty problem: the true objective is hidden or imperfectly represented by a proxy. The thesis core instead treats externally imposed reward-function changes as environmental non-stationarity. That boundary is already locked by selected `SRC-8396F66954` and `SRC-FE2C0A3E00`.

# Learning to Balance Mixed Adversarial Attacks for Robust Reinforcement Learning

## Περιεχόμενο

Η εργασία εισάγει ASA-MDP και ASA-PPO για zero-sum adversarial training όταν attacker κατανέμει budget ταυτόχρονα σε state/observation και action perturbations. Η αξιολόγηση αφορά action-only, observation-only και mixed adversarial attacks.

## Απόφαση scope

Η τρέχουσα διπλωματική εξετάζει κυρίως non-adversarial uncertainty και εξωγενείς environmental changes: stochastic action failures, observation noise, reward/dynamics drift και latent-context changes. Ένας adaptive malicious adversary αποτελεί διαφορετικό threat model με διαφορετικές assumptions, optimization objective και severity interpretation.

Η πηγή είναι τεχνικά σχετική με robustness, αλλά η ένταξή της θα διεύρυνε το scope προς adversarial machine learning και θα καθιστούσε μη συγκρίσιμες τις διαταραχές. Το adversarial scenario έχει ήδη οριστεί εκτός βασικού benchmark.

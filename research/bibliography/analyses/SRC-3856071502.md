# Bayesian Online Changepoint Detection

## Βιβλιογραφική ταυτότητα

- **Συγγραφείς:** Ryan Prescott Adams, David J. C. MacKay
- **Έτος:** 2007
- **Τύπος πηγής:** πρωτογενής μεθοδολογική εργασία Bayesian online inference
- **DOI / arXiv / URL:** arXiv:0710.3742 — https://arxiv.org/abs/0710.3742
- **Πρωτότυπο που ελέγχθηκε:** `πρωτότυπα/SRC-3856071502.pdf`

## Σκοπός και ερευνητικό ερώτημα

Η εργασία αναπτύσσει online Bayesian μέθοδο για την ανίχνευση απότομων αλλαγών στις γενετικές παραμέτρους μιας ακολουθίας δεδομένων. Αντί να εντοπίζει εκ των υστέρων όλα τα segments, υπολογίζει σε κάθε χρονική στιγμή την posterior distribution του run length, δηλαδή του χρόνου από το πιο πρόσφατο changepoint, χρησιμοποιώντας μόνο παρατηρήσεις που έχουν ήδη φτάσει.

Για την παρούσα διπλωματική, η πηγή είναι μεθοδολογικά υποστηρικτική. Παρέχει έναν σαφή probabilistic detector και confidence representation για πιθανές περιβαλλοντικές αλλαγές, αλλά δεν είναι reinforcement-learning algorithm, δεν προσαρμόζει πολιτική και δεν μετρά από μόνη της resilience ή recovery.

## Σύνοψη

Ο BOCPD διατηρεί πολλαπλές υποθέσεις για το τρέχον run length. Σε κάθε νέο datum, probability mass είτε μεταφέρεται σε μεγαλύτερο run length, αν θεωρείται ότι συνεχίζεται το ίδιο segment, είτε επανέρχεται στο μηδέν, αν θεωρείται πιθανό changepoint. Η μετάβαση ελέγχεται από hazard function, ενώ η predictive likelihood του νέου datum καθορίζει πόσο συμβατό είναι το observation με κάθε ενεργή υπόθεση.

Η μέθοδος είναι modular: ο μηχανισμός changepoint inference χωρίζεται από το probabilistic observation model. Με conjugate exponential-family models, τα sufficient statistics ενημερώνονται incremental και η posterior run-length distribution υπολογίζεται ακριβώς υπό τις υποθέσεις του μοντέλου. Το framework εφαρμόζεται σε τρία πραγματικά datasets με αλλαγές μέσης τιμής, διακύμανσης ή event rate.

## Μεθοδολογία

- **Δεδομένα ή περιβάλλον:** sequential observations χωρισμένα σε product-partition segments. Παραδείγματα: well-log measurements, Dow Jones daily returns και coal-mine disaster events.
- **Μοντέλα / αλγόριθμοι:** Bayesian message passing για posterior run length, hazard function για prior changepoint probability και pluggable predictive models, ιδιαίτερα conjugate exponential-family likelihoods.
- **Baselines:** η εργασία δεν παρουσιάζει εκτενή συγκριτική benchmark αξιολόγηση με πολλαπλούς detectors· ο κύριος στόχος είναι η παραγωγή και επίδειξη της μεθόδου.
- **Μετρικές:** posterior probability του run length, predictive mean/variance και ποιοτική αντιστοίχιση posterior resets με γνωστές ή ερμηνεύσιμες αλλαγές.
- **Πειραματική διαδικασία:** causal online update για κάθε νέο observation. Ο αλγόριθμος υπολογίζει growth probabilities, changepoint probability, evidence, posterior run-length distribution και ανανεωμένα sufficient statistics.

## Κύρια ευρήματα

1. **Η online detection μπορεί να εκφράζει αβεβαιότητα αντί να παράγει μόνο binary alarm.** Η posterior distribution πάνω στο run length επιτρέπει να γνωρίζουμε πόσο πιθανό είναι να συνέβη πρόσφατη αλλαγή και πόση αβεβαιότητα υπάρχει για τον χρόνο της. Τεκμηρίωση: σελ. 1–3, Sections 1–2.
2. **Η hazard function κωδικοποιεί prior παραδοχές για τη συχνότητα αλλαγών.** Σε memoryless geometric prior, το hazard είναι σταθερό 1/λ. Άρα ο detector δεν είναι parameter-free: η prior συχνότητα αλλαγής επηρεάζει την ευαισθησία του. Τεκμηρίωση: σελ. 2, Section 2.1.
3. **Ο observation model είναι κρίσιμο μέρος του detector.** Η predictive likelihood πρέπει να αντανακλά το σήμα που αναμένεται να μεταβληθεί. Λανθασμένο likelihood ή ανεπαρκή features μπορούν να αποκρύψουν περιβαλλοντική αλλαγή ή να δημιουργήσουν false alarms. Τεκμηρίωση: σελ. 1–3, Sections 1–2.3.
4. **Η ακριβής μέθοδος έχει γραμμικό worst-case κόστος ανά timestep.** Pruning μικρής posterior mass μπορεί να μειώσει την average complexity περίπου στην αναμενόμενη διάρκεια run, αλλά εισάγει approximation threshold. Τεκμηρίωση: σελ. 3, Section 2.4.
5. **Μετά από changepoint αυξάνεται εύλογα η predictive uncertainty.** Στο well-log παράδειγμα, posterior reset και αύξηση predictive variance εμφανίζονται γύρω από απότομες αλλαγές μέσης τιμής. Τεκμηρίωση: σελ. 4, Section 3.1 και Figure 2.
6. **Η μέθοδος είναι detector, όχι adaptation mechanism.** Η έξοδος πρέπει να συνδεθεί με ξεχωριστή απόφαση για policy update, exploration, reset ή knowledge reuse. Αυτό αποτελεί inference από το scope της εργασίας και πρέπει να δηλώνεται ρητά στη διπλωματική.

## Υποθέσεις και ορισμοί

Changepoint είναι απότομη μεταβολή στις generative parameters της ακολουθίας. Τα observations μέσα σε κάθε segment θεωρούνται i.i.d. υπό segment-specific parameter, και οι parameters διαφορετικών segments θεωρούνται ανεξάρτητες draw από prior. Το run length είναι ο χρόνος από το πιο πρόσφατο changepoint. Η hazard function ορίζει την prior πιθανότητα λήξης ενός run δεδομένης της διάρκειάς του.

Σε RL εφαρμογή, τα raw rewards ή states συνήθως δεν είναι i.i.d. επειδή εξαρτώνται από την policy και τη δυναμική του MDP. Επομένως μια άμεση εφαρμογή BOCPD χρειάζεται κατάλληλη μετατροπή σε statistics, residuals ή episodic summaries και έλεγχο ότι οι assumptions είναι επαρκείς.

## Περιορισμοί και απειλές εγκυρότητας

Η μέθοδος υποθέτει απότομα changepoints και ανεξαρτησία segment parameters. Δεν καλύπτει απευθείας gradual drift, recurring contexts με συσχετισμένη προηγούμενη γνώση ή αλλαγές που συνυπάρχουν με policy learning. Το hazard prior και το predictive model επηρεάζουν σημαντικά τα alarms. Τα πειράματα είναι demonstrations σε τρία datasets και δεν παρέχουν RL-specific baselines, detection F1 across seeds ή post-detection adaptation evaluation. Το ακριβές inference μπορεί να γίνει ακριβό σε μακρές runs, ενώ pruning απαιτεί threshold. Επίσης, posterior probability αλλαγής δεν προσδιορίζει αυτομάτως τη σοβαρότητα της αλλαγής ή την κατάλληλη απόκριση του agent.

## Σχέση με άλλες πηγές

Το `SRC-95C9DAEE68` ενσωματώνει change detection σε RL detection–adaptation frameworks και δείχνει γιατί reward-only signals μπορεί να μην επαρκούν. Το BOCPD παρέχει γενικό Bayesian υπόβαθρο για online uncertainty και run-length inference. Το `SRC-81A15E6905` αφορά robustness απέναντι σε action perturbation χωρίς να ανιχνεύει απαραίτητα change point.

## Χρήση στη διπλωματική

- **Προτεινόμενα κεφάλαια:** θεωρητικό υπόβαθρο, σχετικές εργασίες, change detection, πειραματική μεθοδολογία.
- **Ισχυρισμοί που μπορεί να υποστηρίξει:** online detector μπορεί να διατηρεί posterior αβεβαιότητα για τον χρόνο αλλαγής· η prior συχνότητα αλλαγής και το observation model είναι ρητές design choices· detector output πρέπει να διαχωρίζεται από adaptation.
- **Τι δεν πρέπει να ισχυριστούμε από αυτή την πηγή:** ότι BOCPD είναι από μόνο του resilient agent, ότι είναι parameter-free, ότι οι i.i.d. assumptions ισχύουν αυτομάτως σε RL trajectories ή ότι αποδίδει καλύτερα από άλλους detectors στο δικό μας environment χωρίς πείραμα.
- **Ρόλος:** υποστηρικτική

## Απαιτούμενα αποσπάσματα

Καταγράφηκαν τεκμήρια για posterior run length, hazard assumptions, modular observation models, computational cost και τον διαχωρισμό detector/adaptation.

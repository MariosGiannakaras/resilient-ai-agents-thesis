# Evidence — Decision Making Under Uncertainty: Theory and Application

## E1 — An MDP makes the sequential decision model explicit
- **Type:** faithful paraphrase
- **Location:** Chapter 4, Sections 4.1–4.2
- **Claim:** A Markov decision process represents a sequential decision problem through states, actions, transition probabilities, rewards or utilities, and a policy.
- **Status:** verified

### Faithful paraphrase
Kochenderfer formulates sequential decision making with a state that summarizes the information needed for future evolution, a set of available actions, transition probabilities that describe how actions change the state, and a reward or utility signal that evaluates outcomes. A policy specifies how actions are selected from states, and dynamic-programming methods evaluate or improve that policy through expected future utility.

### Context and limits
The Markov formulation requires the chosen state representation to contain the relevant information. When decision-relevant information is hidden, a partially observable formulation may be more appropriate.

### Thesis use
Use this source for the mathematical definition of the controlled GridWorld MDP and for the distinction between model specification and learned policy.

### Citation
Kochenderfer (2015), Chapter 4, Sections 4.1–4.2.

## E2 — GridWorld is a transparent worked example, not a claim of realism
- **Type:** faithful paraphrase
- **Location:** Section 4.2.5, Grid World Example
- **Claim:** A grid-based problem can expose the relation among transitions, rewards, value functions, and policies in a small inspectable state space.
- **Status:** verified

### Faithful paraphrase
The book's grid-world example defines a finite spatial state space, local actions, stochastic movement, and state-dependent utility, then uses dynamic programming to compute values and a policy. The example is useful because the complete model and resulting decisions can be inspected directly.

### Context and limits
The pedagogical transparency of a grid world does not establish external validity for complex real systems.

### Thesis use
Justify GridWorld as a controlled, inspectable experimental instrument while explicitly limiting claims to the tested environment family.

### Citation
Kochenderfer (2015), Section 4.2.5.

## E3 — Model uncertainty creates an exploration–exploitation problem
- **Type:** faithful paraphrase
- **Location:** Chapter 5, especially Sections 5.1 and 5.3–5.4
- **Claim:** When transition or reward models are not known, interaction has both immediate task value and information value.
- **Status:** verified

### Faithful paraphrase
Chapter 5 treats unknown model parameters as a source of uncertainty that must be resolved through data. Bayesian model-based methods maintain beliefs over unknown parameters and can plan in the resulting information state, while model-free methods such as Q-learning and Sarsa learn value estimates directly from experience. In either case, exploration determines which evidence becomes available to the learner.

### Context and limits
These presentations primarily assume a stationary underlying problem while the learner reduces its initial uncertainty. They do not automatically solve abrupt repeated regime changes.

### Thesis use
Separate initial model uncertainty from environmental non-stationarity and state clearly which information each baseline retains or forgets after a change.

### Citation
Kochenderfer (2015), Chapter 5.

## E4 — State uncertainty leads naturally to belief-state decision making
- **Type:** faithful paraphrase
- **Location:** Chapter 6, Sections 6.1–6.2
- **Claim:** When the true state is not directly observable, a POMDP represents observations separately and decisions can be based on a belief distribution over possible states.
- **Status:** verified

### Faithful paraphrase
The POMDP formulation adds uncertainty about the current state to the sequential decision problem. The agent updates a belief state from previous beliefs, actions, and observations, and this information state can then be used as the input to planning or policy execution.

### Context and limits
A POMDP is not required merely because rewards are noisy; the need arises when decision-relevant state information itself is uncertain or hidden.

### Thesis use
Declare whether each observation-corruption experiment preserves access to the true Markov state, supplies only a corrupted observation, or requires an explicit belief-state agent.

### Citation
Kochenderfer (2015), Chapter 6, Sections 6.1–6.2.

## E5 — Online planning, model learning, and model-free learning are distinct solution families
- **Type:** faithful paraphrase
- **Location:** Chapters 4–5
- **Claim:** The book separates planning with a model, Bayesian/model-based learning under model uncertainty, and model-free value learning.
- **Status:** verified

### Faithful paraphrase
Chapter 4 surveys offline and online planning when an MDP model is available, including forward search, sparse sampling, and Monte Carlo tree search. Chapter 5 then addresses uncertainty about the model and separately presents model-free methods such as Q-learning and Sarsa. These families have different information requirements and computational trade-offs.

### Thesis use
Do not compare a model-free learner and an online planner as if they receive identical prior information; record simulator/model access as part of the experimental condition.

### Citation
Kochenderfer (2015), Chapters 4–5.

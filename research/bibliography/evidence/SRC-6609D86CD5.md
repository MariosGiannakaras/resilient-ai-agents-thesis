# Evidence — Reinforcement Learning in Nonstationary Environments

> Evidence scope: the repository record contains the institutional thesis metadata and abstract, not the full dissertation text. Claims below are intentionally limited to information stated in that record.

## E1 — Recency-weighted online learning is a natural memoryless response to nonstationarity
- **Type:** faithful paraphrase
- **Location:** Abstract
- **Claim:** The dissertation describes the dominant earlier approach to nonstationary RL as online learning that gives greater emphasis to recent experience as the environment changes.
- **Status:** verified

### Faithful paraphrase
Choi notes that much earlier nonstationary RL work assumes changes occur slowly enough for adaptation and responds by weighting recent experience more strongly than older experience. In this sense the learner adapts by forgetting or discounting information that may no longer describe the current dynamics.

### Thesis use
Use recency/decay Q-learning as a simple memoryless nonstationary baseline.

### Citation
Choi (2000), institutional abstract.

## E2 — Memoryless adaptation pays repeated relearning cost when an old regime returns
- **Type:** faithful paraphrase
- **Location:** Abstract
- **Claim:** If previous dynamics recur, a learner that has discarded old information must learn that environment again.
- **Status:** verified

### Faithful paraphrase
The abstract explicitly contrasts memoryless online learning with environments whose dynamics repeat. When the environment reverts to a previous regime, the memoryless learner cannot simply recover the old model from stored context and instead must relearn it from new interaction.

### Thesis use
For recurring regimes, compare first-occurrence recovery with later-occurrence recovery and include a no-memory/recency-only comparator.

### Citation
Choi (2000), institutional abstract.

## E3 — Recurrent nonstationarity can be modeled through hidden MDP modes
- **Type:** faithful paraphrase
- **Location:** Abstract
- **Claim:** One model in the dissertation represents environmental change through a finite set of hidden modes, each corresponding to an MDP, with mode switching governed by another Markov process.
- **Status:** verified

### Faithful paraphrase
The dissertation's first part assumes that nonstationary dynamics belong to a fixed number of latent modes. Each mode specifies an MDP and the evolution of the active mode follows a Markov process. This supplies a formal recurring-regime interpretation rather than treating every change as a previously unseen task.

### Context and limits
The finite hidden-mode assumption is a structural prior. It does not cover arbitrary new regimes unless the model is extended.

### Thesis use
Use this as background for a finite context library and explicitly test a regime that is absent from the library.

### Citation
Choi (2000), institutional abstract.

## E4 — Hidden regime and partially observed physical state are related but not identical
- **Type:** faithful paraphrase plus scope clarification
- **Location:** Abstract
- **Claim:** The dissertation discusses the relationship between its hidden-mode model and POMDPs.
- **Status:** verified

### Faithful paraphrase
Because the active environmental mode is not directly observed, the problem has a partial-information structure. However, uncertainty over which dynamics regime is active is conceptually different from ordinary sensor corruption or uncertainty over the agent's current physical state.

### Thesis use
Keep `latent_regime_uncertainty` separate from `observation_corruption` even when both can be represented using belief-state machinery.

### Citation
Choi (2000), institutional abstract.

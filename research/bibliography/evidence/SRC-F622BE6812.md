# Evidence — Exploration by Random Network Distillation

## E1 — RND uses prediction error as an intrinsic exploration bonus
- **Type:** faithful paraphrase
- **Location:** Abstract; Sections 1 and 2.2
- **Claim:** A trainable predictor learns to reproduce features generated by a fixed randomly initialized target network, and prediction error is used as intrinsic reward.
- **Status:** verified

### Faithful paraphrase
Burda et al. define Random Network Distillation with two neural networks. The target network is initialized randomly and then kept fixed, while a predictor is trained on observations collected by the agent. The squared prediction error tends to be larger on observations unlike those in the predictor's training data, making the error usable as a novelty-driven exploration bonus.

### Thesis use
Use RND as background for novelty-directed exploration after a detected shift; prefer a count-based/tabular analogue unless a neural implementation passes the resource feasibility gate.

### Citation
Burda et al. (2018), Abstract and Sections 1 and 2.2.

## E2 — A deterministic target reduces one source of the noisy-TV problem
- **Type:** faithful paraphrase
- **Location:** Section 1; Section 2.2.1
- **Claim:** RND chooses a deterministic prediction target to avoid the intrinsic-reward failure caused by stochastic forward-prediction targets.
- **Status:** verified

### Faithful paraphrase
Prediction-error exploration can be attracted to unpredictable stochastic events when the target itself is random, as in forward-dynamics prediction around a source of visual noise. RND instead predicts a deterministic fixed-network output for the current observation, removing target stochasticity and the associated aleatoric-error component from that prediction problem.

### Context and limits
A deterministic target does not eliminate every source of prediction error. Error can still reflect limited data, model mismatch, optimization behavior, normalization, or representation effects.

### Citation
Burda et al. (2018), Section 1 and Section 2.2.1.

## E3 — Prediction error is not a calibrated change probability
- **Type:** faithful paraphrase plus scope clarification
- **Location:** Section 2.2.1, Sources of Prediction Errors
- **Claim:** Prediction error can arise from training-data scarcity, stochasticity, model misspecification, and learning dynamics.
- **Status:** verified

### Faithful paraphrase
The paper explicitly decomposes prediction error into several possible causes. Data scarcity is the component useful for novelty exploration, while stochastic targets, limited model capacity or missing information, and imperfect optimization can also increase error. RND is designed to remove some unwanted causes but the remaining scalar error is still not a calibrated posterior probability that the environment has changed.

### Thesis use
If a novelty score contributes to a detector, calibrate it with held-out shifts and report false alarms, missed changes, and detection delay.

### Citation
Burda et al. (2018), Section 2.2.1.

## E4 — Intrinsic reward is itself non-stationary
- **Type:** faithful paraphrase
- **Location:** Section 2.3
- **Claim:** The intrinsic reward changes as the predictor learns even when the external task reward is fixed.
- **Status:** verified

### Faithful paraphrase
As observations become familiar to the predictor, their RND error decreases. The paper therefore treats the intrinsic reward stream as non-stationary and separates its value estimation from the stationary extrinsic reward stream when combining the two objectives.

### Thesis use
Log intrinsic and extrinsic rewards separately and state whether the novelty estimator is preserved, reset, or partially reset after a detected environmental change.

### Citation
Burda et al. (2018), Section 2.3.

## E5 — Intrinsic and extrinsic return should remain distinguishable
- **Type:** faithful paraphrase
- **Location:** Abstract; Section 2.3
- **Claim:** The method maintains separate value estimates for intrinsic and extrinsic reward streams before combining them.
- **Status:** verified

### Faithful paraphrase
The authors use separate value heads so the two reward streams can have different episodic treatment and discount factors before being combined for policy optimization. This design makes clear that successful exploration and successful task performance are not the same measurement.

### Thesis use
Do not claim better resilience from increased novelty reward alone; require corresponding improvements in task return, recovery metrics, and safety outcomes.

### Citation
Burda et al. (2018), Abstract and Section 2.3.

# Evidence — Efficient Adaptation of Reinforcement Learning Agents to Sudden Environmental Change

## E1 — Source-task learning and post-novelty adaptation are separate phases

- **Type:** faithful paraphrase
- **Location:** Chapters 3–4; Figure 4.2
- **Claim:** The evaluation distinguishes learning a stationary source task from adapting after a novelty changes the target environment.
- **Status:** verified

### Faithful paraphrase

Balloch's experimental framework first allows an agent to learn the original task and then introduces a novelty that changes the environment. Performance commonly drops when the new task begins, after which the experiment measures how effectively the agent learns the altered reward or transition structure.

### Thesis use

Use explicit pre-change and post-change phases and preserve the full recovery curve rather than reporting only final return.

### Citation

Balloch (2024), Chapters 3–4 and Figure 4.2.

## E2 — Adaptive efficiency measures successful post-change convergence time

- **Type:** faithful paraphrase
- **Location:** Chapter 4; Table 4.2
- **Claim:** Adaptive efficiency is the number of interaction steps from the beginning of the novel task until convergence on the second task, computed only for runs that converge on both tasks.
- **Status:** verified

### Faithful paraphrase

Lower adaptive-efficiency values indicate faster successful adaptation, but the metric conditions on convergence. Runs that fail to learn either task do not enter the reported mean and variance.

### Context and limits

Ignoring failed runs can create survivorship bias and make a method look fast precisely because unsuccessful seeds have been excluded.

### Thesis use

Always report adaptation/recovery time together with the fraction of seeds that reach the corresponding threshold.

### Citation

Balloch (2024), Chapter 4 and Table 4.2.

## E3 — Adaptation speed and final post-change performance are distinct

- **Type:** faithful paraphrase
- **Location:** Chapter 4; Figure 4.2 and surrounding metric discussion
- **Claim:** An agent can adapt quickly without recovering to its previous performance level, so time-to-convergence and final target-task performance measure different outcomes.
- **Status:** verified

### Faithful paraphrase

The dissertation evaluates how quickly the learning curve stabilizes after novelty and separately how well the agent ultimately performs on the new task. A short adaptation interval does not imply that the new steady-state return matches the source-task performance.

### Thesis use

Report both time-to-recovery/threshold and final post-change return.

### Citation

Balloch (2024), Chapter 4 and Figure 4.2.

## E4 — Transfer area under the curve summarizes the adaptation trajectory but is conditional

- **Type:** faithful paraphrase
- **Location:** Chapter 4; Table 4.3
- **Claim:** Transfer AUC combines source-task final reward with the area under the target-task reward curve and is reported only for runs that converge on the source task.
- **Status:** verified

### Faithful paraphrase

The transfer-AUC metric rewards both competence before novelty and strong reward accumulation while learning the new task. Its reported statistics exclude runs that failed to converge on the first task, so the conditioning rule is part of the metric definition.

### Thesis use

If an area-under-recovery score is used, publish the exact normalization and treatment of failed runs.

### Citation

Balloch (2024), Table 4.3.

## E5 — Exploration effectiveness depends on the novelty and environment

- **Type:** faithful paraphrase
- **Location:** Chapter 4; Figures 4.3–4.5
- **Claim:** The dissertation does not find one exploration method that dominates across all tested novelty conditions.
- **Status:** verified

### Faithful paraphrase

The exploration experiments compare several strategies across discrete and continuous-control novelty tasks. Relative performance changes with the novelty and environment, illustrating that an exploration mechanism that accelerates adaptation in one setting can be less effective in another.

### Thesis use

Evaluate exploration and recency mechanisms across more than one shift type before drawing comparative conclusions.

### Citation

Balloch (2024), Chapter 4 and Figures 4.3–4.5.

## E6 — NovGrid supports hidden semantic or rule changes

- **Type:** faithful paraphrase
- **Location:** Chapter 3; Figure 3.1
- **Claim:** The benchmark includes novelties that alter task semantics without directly revealing the new rule to the agent.
- **Status:** verified

### Faithful paraphrase

Examples include changing which key opens a door and changing lava from a terminal hazard into a traversable or safe region. The visual objects can remain recognizable while the consequences of interacting with them change, requiring the agent to discover the new semantics through experience.

### Thesis use

Include rule/semantic shifts that do not provide an oracle change label.

### Citation

Balloch (2024), Chapter 3 and Figure 3.1.

## E7 — Different replay objectives can require different priorities

- **Type:** faithful paraphrase
- **Location:** Chapter 5, Dual Objective Priority Sampling
- **Claim:** In the dissertation's model-based RL setting, world-model learning and actor–critic learning can benefit from different priority signals applied to the same replay transitions.
- **Status:** verified

### Context and limits

This is motivation for component-specific replay design in model-based RL, not evidence that the thesis's tabular agents require DOPS.

### Thesis use

If a model-based ablation is added, document replay/recency policy separately for each learning component.

### Citation

Balloch (2024), Chapter 5.

## E8 — Non-convergence is an outcome, not missing data

- **Type:** faithful paraphrase
- **Location:** Tables 4.2–4.3 and appendix metric notes
- **Claim:** Several adaptation metrics are conditional on convergence, so convergence frequency must be reported as a separate result.
- **Status:** verified

### Thesis use

For every time-to-threshold or convergence statistic, report the denominator and the percentage of runs that successfully reached the threshold.

### Citation

Balloch (2024), Tables 4.2–4.3 and appendix metric notes.

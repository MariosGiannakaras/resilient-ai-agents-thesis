# Evidence — Online Robust Planning Under Model Uncertainty: A Sample-Based Approach

## Evidence E1 — RSS is robust online planning under model misspecification
- **Type:** faithful paraphrase
- **Location:** Abstract; Sections 1–1.1
- **Claim:** Robust Sparse Sampling extends online sample-based planning to robust MDPs by optimizing a robust value under uncertainty in the transition model.
- **Thesis use:** robust-planning comparator
- **Topics:** robust MDP; online planning; model misspecification
- **Status:** verified

### Faithful paraphrase
RSS plans from the current state using samples from an approximate generative model, but unlike nominal Sparse Sampling it evaluates actions against a set of plausible transition models and optimizes for the worst case within that set. The method is therefore a robustness mechanism for imperfect dynamics models rather than a model-free continual learner.

## Evidence E2 — The uncertainty model assumes a bounded transition-model error
- **Type:** faithful paraphrase
- **Location:** Section 2.1, Equations (1)–(3)
- **Claim:** The true transition kernel is assumed to lie within a Total-Variation radius around the approximate model, with a rectangular uncertainty-set structure.
- **Thesis use:** uncertainty-model disclosure
- **Topics:** Total Variation; uncertainty radius; rectangularity
- **Status:** verified

### Faithful paraphrase
For each state-action pair, the paper assumes that the distance between the true transition distribution and the approximate generative model is bounded by a radius ρ. The robust MDP uses the common rectangularity assumption, so uncertainty is modeled independently across state-action pairs.

### Limitation
The radius and uncertainty-set structure are assumptions or inputs. They should not be confused with an online changepoint estimate.

## Evidence E3 — Robust planning has finite-sample guarantees but still incurs planning cost
- **Type:** faithful paraphrase
- **Location:** Section 1.1; theoretical analysis
- **Claim:** RSS provides a finite-sample value approximation guarantee whose complexity is independent of the size of the state space.
- **Thesis use:** computational trade-off reporting
- **Topics:** finite-sample guarantee; lookahead; samples
- **Status:** verified

### Faithful paraphrase
The paper derives an error bound that can be reduced by choosing sufficient planning depth and sample width. Independence from state-space size does not imply negligible runtime: online lookahead still depends on planning horizon, action branching, sample width, and the robust backup computation.

## Evidence E4 — Robustness can improve performance as model error grows
- **Type:** faithful paraphrase
- **Location:** experiments, including stochastic FrozenLake
- **Claim:** RSS is reported to outperform nominal Sparse Sampling when the approximate transition model is sufficiently misspecified and to reduce catastrophic failures in the tested settings.
- **Thesis use:** controlled model-error scenario
- **Topics:** FrozenLake; model uncertainty; failure rate
- **Status:** verified

### Faithful paraphrase
In the reported stochastic navigation experiment, nominal planning with an erroneous model degrades as transition-model uncertainty increases, whereas RSS maintains stronger return and failure behavior over the tested uncertainty levels. A planner using the true dynamics remains an oracle-style upper reference.

### Limitation
This is model misspecification under a specified uncertainty set, not an unknown temporal changepoint.

## Evidence E5 — Robustness may trade nominal performance for protection
- **Type:** faithful paraphrase
- **Location:** empirical results and discussion
- **Claim:** Worst-case planning can be conservative when model error is small, while becoming more advantageous as misspecification increases.
- **Thesis use:** conservativeness reporting
- **Topics:** nominal utility; disturbed utility; safety trade-off
- **Status:** verified

### Faithful paraphrase
Optimizing against adverse transition models can sacrifice some nominal performance when the approximate model is already accurate. The value of the robust planner becomes clearer as model error increases, so evaluation should report both clean/low-error utility and performance under misspecification.

## Evidence E6 — RSS is not a change detector or a continued-learning mechanism
- **Type:** thesis-safe inference from the formulation
- **Location:** Sections 2–6
- **Claim:** RSS plans with a predeclared model-uncertainty set and does not introduce changepoint detection, regime memory, or online relearning across repeated environmental changes.
- **Thesis use:** mechanism taxonomy
- **Topics:** robustness; adaptation boundary; detector
- **Status:** verified

## Avoid overclaiming
This source supports a model-based robustness comparator. It does not establish online resilience to unannounced regime changes, and a known uncertainty radius should be reported as prior/oracle information when used in experiments.

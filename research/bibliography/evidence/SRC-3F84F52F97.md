# Evidence — CARL: A Benchmark for Contextual and Adaptive Reinforcement Learning

## E1 — Contextual MDPs represent families of related task instances

- **Type:** faithful paraphrase
- **Location:** Section 2
- **Claim:** CARL models related environment instances with common state and action spaces but context-dependent transition and reward functions.
- **Status:** verified

### Faithful paraphrase

Benjamins et al. formulate CARL environments as contextual MDPs. Each sampled instance is defined by a context and retains a common task interface, while transition dynamics, rewards, and the subset of reachable states may differ across instances.

### Context and limits

A shared interface does not imply identical difficulty or the same optimal policy.

### Thesis use

Represent GridWorld configurations as context-resolved MDP instances with recorded context values.

### Citation

Benjamins et al. (2021), Section 2.

## E2 — Explicit and implicit context provide different information to the agent

- **Type:** faithful paraphrase
- **Location:** Section 4
- **Claim:** Explicit context is supplied directly, while implicit context must be inferred from observations, entangling representation learning with policy generalization.
- **Status:** verified

### Faithful paraphrase

CARL distinguishes context information that is directly available to the policy from context that is hidden inside the ordinary observation. When context is implicit, the agent must first extract the relevant environmental factors before it can condition its behavior on them, so representation learning becomes part of the generalization problem.

### Thesis use

State explicitly whether the current regime or change variable is observable, hidden, or available only to an oracle baseline.

### Citation

Benjamins et al. (2021), Section 4.

## E3 — Reproducible generalization requires explicit context bounds and distributions

- **Type:** faithful paraphrase
- **Location:** Sections 1–2 and benchmark design
- **Claim:** CARL provides defined ranges and sampling distributions for context variables so train and test instance populations can be reconstructed.
- **Status:** verified

### Faithful paraphrase

The benchmark was motivated in part by inconsistent hand-designed task variations across prior studies. CARL instead exposes context features together with bounds and distributions, enabling researchers to specify how training and test instances are sampled and how far a test context lies from the training distribution.

### Context and limits

Reproducibility of a range does not establish that the chosen severity is scientifically appropriate.

### Thesis use

Persist resolved context values, generation distributions, seeds, and severity bands for every run.

### Citation

Benjamins et al. (2021), Sections 1–2.

## E4 — Multiple seeds and sampled contexts are needed for generalization claims

- **Type:** faithful paraphrase
- **Location:** Experimental methodology
- **Claim:** The CARL demonstrations evaluate agents over multiple random seeds and many sampled contexts rather than relying on one environment instance.
- **Status:** verified

### Faithful paraphrase

The paper's main demonstrations use repeated training runs and broad context sampling, with implementation and reproduction details provided alongside the experiments. The purpose is to characterize behavior over a population of environment instances rather than a single favorable configuration.

### Thesis use

Use multiple agent seeds and multiple environment instances within each severity condition; determine the final counts from pilot variance and compute constraints rather than copying CARL's counts mechanically.

### Citation

Benjamins et al. (2021), experimental methodology.

## E5 — In-distribution performance does not guarantee OOD generalization

- **Type:** faithful paraphrase
- **Location:** Experimental results
- **Claim:** Performance degrades as contexts move farther from the training distribution, and explicit context can help in some settings without providing a universal solution.
- **Status:** verified

### Faithful paraphrase

CARL experiments show that increasing context variation can make training harder and that agents often behave best near the contexts represented during training. In out-of-distribution evaluations such as altered gravity conditions, performance can decline substantially as the test context moves farther from the training distribution.

### Context and limits

The quantitative findings depend on the specific agents and context distributions used in the paper.

### Thesis use

Define separate ID, near-OOD, and far-OOD test bands rather than reporting one generalization average.

### Citation

Benjamins et al. (2021), experimental results.

## E6 — CARL's reported experiments are static-context generalization tests, not continual recovery tests

- **Type:** faithful paraphrase
- **Location:** Discussion and future work
- **Claim:** The paper primarily evaluates fixed contexts and does not empirically establish continual adaptation to within-run dynamic context changes.
- **Status:** verified

### Faithful paraphrase

Although the CARL framework can expose many environmental factors, the reported study focuses on static contexts and largely varies individual context features. Dynamic contexts and continual-learning evaluations are identified as future directions rather than demonstrated results.

### Thesis use

Use CARL for static context/generalization design principles and keep changepoint/recovery experiments conceptually separate.

### Citation

Benjamins et al. (2021), discussion and future work.

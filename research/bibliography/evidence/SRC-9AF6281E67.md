# Evidence — Policy-Conditioned Uncertainty Sets for Robust Markov Decision Processes

## E1 — Rectangular uncertainty sets can be excessively conservative

- **Type:** faithful paraphrase
- **Location:** Abstract; Introduction; Section 2.1
- **Claim:** Independently applying worst-case transition uncertainty at each state or state–action pair is computationally convenient but can combine local worst cases into policies that are too conservative.
- **Status:** verified

### Faithful paraphrase

Tirinzoni et al. explain that `s,a`-rectangular and `s`-rectangular sets make robust MDPs tractable by constraining transition uncertainty independently across local parts of the state space. This independence can be overly pessimistic because it permits nature to select unfavorable local transitions simultaneously even when the available trajectory data do not support that joint combination.

### Context and limits

Non-rectangular uncertainty is not automatically superior; it can be harder to optimize and depends on the quality of whatever global structure is imposed.

### Thesis use

Expose uncertainty-set structure and nominal-versus-worst-case utility when interpreting a robust baseline.

### Citation

Tirinzoni et al. (2018), Abstract, Introduction, and Section 2.1.

## E2 — Trajectory-level feature constraints couple uncertainty across states

- **Type:** faithful paraphrase
- **Location:** Section 3.1, Definition 2
- **Claim:** The proposed uncertainty set constrains candidate dynamics through feature expectations measured over trajectories generated by a reference policy.
- **Status:** verified

### Faithful paraphrase

Instead of assigning an independent uncertainty constraint to every state–action pair, the method defines features over state–action–next-state triples and requires candidate transition dynamics to reproduce aggregate feature expectations observed in reference-policy trajectories. These marginal constraints can encode properties shared across multiple regions of the state space.

### Context and limits

The feature function is domain-dependent and introduces prior structural knowledge. A poor feature set can fail to constrain important aspects of the dynamics.

### Thesis use

If a non-rectangular robust comparator is considered, record `uncertainty_set_construction`, the feature definitions, and the amount of reference-policy data used.

### Citation

Tirinzoni et al. (2018), Section 3.1, Definition 2.

## E3 — Reference-policy data and target-policy optimization are deliberately separated

- **Type:** faithful paraphrase
- **Location:** Introduction; Section 3
- **Claim:** The uncertainty set is estimated from trajectories produced by a potentially suboptimal reference policy, while robust performance is optimized for a different control policy.
- **Status:** verified

### Faithful paraphrase

The paper's off-policy robust formulation uses the behavior of the reference policy to constrain plausible dynamics and simultaneously searches for a control policy that performs well against the worst dynamics consistent with those constraints. This separates how information is collected from which policy is ultimately optimized.

### Context and limits

Coverage of the reference trajectories determines which global properties can be learned reliably. The method does not remove the need to report the reference-policy data budget.

### Thesis use

Keep offline/reference data access separate from online interaction budget when comparing robust agents.

### Citation

Tirinzoni et al. (2018), Introduction and Section 3.

## E4 — Global structural knowledge trades conservativeness against stronger assumptions

- **Type:** faithful paraphrase
- **Location:** Section 3.1; experimental motivation
- **Claim:** Encoding known global trajectory properties can reduce over-conservatism, but those properties constitute additional prior information about the MDP.
- **Status:** verified

### Faithful paraphrase

The paper gives examples of features that encode events such as entering unsafe regions, reaching goals, or respecting known impossible transitions. Matching such feature statistics couples transition probabilities globally and can generalize beyond individually observed state–action pairs. The benefit therefore comes from using meaningful structural knowledge rather than from non-rectangularity alone.

### Thesis use

Treat feature engineering as a prior-information advantage and include it in the fairness/resource ledger.

### Citation

Tirinzoni et al. (2018), Section 3.1.

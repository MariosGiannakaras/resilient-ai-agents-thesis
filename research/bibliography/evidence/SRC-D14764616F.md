# Evidence — Context-Switching and Adaptation: Brain-Inspired Mechanisms for Handling Environmental Changes

## E1 — Stale learned models can cause negative transfer after transition changes

- **Type:** faithful paraphrase
- **Location:** Introduction; Figure 1
- **Claim:** After transition contingencies change, previously learned model information can actively obstruct discovery of the new solution rather than merely being incomplete.
- **Status:** verified

### Faithful paraphrase

The paper illustrates a model-based agent that learns one maze and then enters a second maze with different boundaries. Transition information from the first maze remains in the learned model and can make the planner conclude incorrectly that no route to the goal exists. The correct route may then be discovered only through exploratory transitions that contradict the stale model.

### Context and limits

The example is deterministic spatial navigation and should not be generalized to every form of non-stationarity or to all model-free agents.

### Thesis use

Measure negative transfer explicitly and compare continual warm-start behavior with reset and context-aware alternatives after structural transition changes.

### Citation

Chalmers et al. (2016), Introduction and Figure 1.

## E2 — Context detection, model recall, adaptation, and new-model creation are separate operations

- **Type:** faithful paraphrase
- **Location:** Sections II.B–II.C; Figure 5
- **Claim:** The architecture first evaluates whether the current model still explains recent transitions and then separately chooses among recalling, adapting, or creating a model.
- **Status:** verified

### Faithful paraphrase

The agent stores a short history of recent transitions and estimates how probable that history is under its current and saved models. If the current model no longer explains the observations, the system treats this as evidence of an environmental change. A stored model that better predicts the recent history can be recalled. If no saved model is adequate, the system attempts to adapt the closest model and can create a new model if adaptation fails.

### Context and limits

History length and likelihood thresholds are hyperparameters. Early stochastic transitions can lead to incorrect context assignment or unnecessary model proliferation.

### Thesis use

Log detected context, selected stored model, adaptation attempts, and model-creation events separately. Do not treat context detection as identical to adaptation.

### Citation

Chalmers et al. (2016), Sections II.B–II.C and Figure 5.

## E3 — Repeated-context benchmarks can separate first-time adaptation from recall

- **Type:** faithful paraphrase
- **Location:** Experimental protocol, Section III
- **Claim:** Repeating a sequence of environments allows first exposure and later recall to be evaluated separately under a controlled interaction budget.
- **Status:** verified

### Faithful paraphrase

The study cycles an agent through multiple gridworld environments, keeps it in each environment for a fixed number of trials, and repeats the full environment sequence. The second exposure therefore tests whether previously stored context-specific knowledge can be retrieved rather than learned again from scratch. The experiments also control trial termination and the amount of model updating used by the compared systems.

### Context and limits

The exact grid size, number of repetitions, and update counts are specific to the study and need not be copied literally.

### Thesis use

Include recurring-regime sequences such as `A→B→C→A` and report first-exposure adaptation separately from later recall performance.

### Citation

Chalmers et al. (2016), Section III.

## E4 — Recall of a known context is not the same as adaptation to a novel context

- **Type:** faithful paraphrase
- **Location:** Results and discussion; Figures 7–9
- **Claim:** Performance gains on repeated environments can arise from stored-model recall, while gains on related but novel environments can arise from adapting previously learned structure.
- **Status:** verified

### Faithful paraphrase

The context-switching system can restore previously learned solutions when an environment reappears. The hierarchy also supports faster learning in some new environments when a previously learned model provides a useful starting point. The results therefore contain two different mechanisms: direct recall for known contexts and transfer/adaptation for related but previously unseen contexts.

### Context and limits

The reported benefits depend on the particular environment sequence and model relationships. They do not establish universal compositional generalization.

### Thesis use

Report recall gain, first-exposure adaptation cost, and second-exposure recovery time as separate quantities.

### Citation

Chalmers et al. (2016), results and discussion, Figures 7–9.

## E5 — A finite context library assumes recurring, representable regimes

- **Type:** scope inference grounded in the architecture
- **Location:** Sections II.B–II.C
- **Claim:** Model-library recall is most appropriate when environmental regimes recur and can be represented as distinct models.
- **Status:** verified

### Faithful paraphrase

The method stores environment-specific model hierarchies and searches that library when recent transitions stop matching the active model. This design presupposes that useful prior contexts can recur and that the library remains manageable. A genuinely novel regime may still require adaptation or construction of a new model.

### Thesis use

Include an explicit held-out regime that is absent from the context library and compare hard recall with a no-transfer or fallback mechanism.

### Citation

Chalmers et al. (2016), Sections II.B–II.C.

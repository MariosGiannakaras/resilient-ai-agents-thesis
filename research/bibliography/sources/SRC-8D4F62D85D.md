# Deep Reinforcement Learning That Matters

Peter Henderson, Riashat Islam, Philip Bachman, Joelle Pineau, Doina Precup, David Meger

Proceedings of the Thirty-Second AAAI Conference on Artificial Intelligence (AAAI-18), 2018.

arXiv:1709.06560

This empirical reproducibility study shows that deep-RL results can change materially with random seeds, hyperparameters, network architecture, reward scaling, implementation details, and codebase. It motivates controlled evaluation, sufficient independent runs, explicit implementation reporting, and avoiding conclusions based on selected favorable runs. Protocol-v2 uses it as primary historical evidence for fair cross-family comparison rather than treating library defaults or best seeds as neutral choices.

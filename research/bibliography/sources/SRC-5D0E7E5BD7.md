# Implementation Matters in Deep Policy Gradients: A Case Study on PPO and TRPO

Logan Engstrom, Andrew Ilyas, Shibani Santurkar, Dimitris Tsipras, Firdaus Janoos, Larry Rudolph, Aleksander Madry

2020. arXiv:2005.12729.

Canonical article page: https://arxiv.org/abs/2005.12729

Protocol-v2 closure relevance: demonstrates that code-level implementation choices can materially alter PPO/TRPO behavior and measured performance. This source supports treating the retained deep-RL implementation/version/configuration as part of the scientific method identity and provenance rather than referring to an underspecified algorithm label such as `PPO`. It does not justify selecting settings after final outcomes are observed.

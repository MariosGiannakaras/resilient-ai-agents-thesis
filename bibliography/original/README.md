# Original Bibliography Sources

Place original source files here:
- peer-reviewed papers,
- books/chapters where legally stored,
- technical reports,
- theses/dissertations,
- standards and official documentation,
- exported citation records.

## Rules

- Preserve original files unchanged.
- Record source URL/DOI, retrieval date, license/access status and checksum.
- Do not invent missing metadata.
- Store searchable Markdown conversions in `../markdown/`.
- Store structured reading notes in `../notes/`.
- Verify every citation against the original source before thesis use.
- Do not treat an AI summary as a bibliographic source.
- Review large files and Git LFS/storage policy before commit.

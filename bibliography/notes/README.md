# Bibliography Notes

Create one structured note per verified source.

## Suggested schema

```yaml
citation_key:
title:
authors:
year:
venue:
doi:
url:
source_file:
source_sha256:
verification_status:
```

## Note sections

1. **Verified abstract/summary** — paraphrase, not invented text.
2. **Research question and method.**
3. **Environment/data and experimental design.**
4. **Models/baselines.**
5. **Metrics/statistics.**
6. **Main findings.**
7. **Limitations and threats.**
8. **Relationship to this thesis.**
9. **Useful chapters/sections/pages.**
10. **Short quotations** with exact page numbers and limited use.
11. **Claims this source can support.**
12. **Claims this source does not support.**
13. **Follow-up sources or questions.**

Do not create fabricated DOI, venue, page or quotation data.

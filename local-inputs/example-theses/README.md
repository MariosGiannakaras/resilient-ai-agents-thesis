# Local Example Theses

Place the completed thesis/dissertation files supplied by the user in this folder for the future `T-701` structural/style review.

## Intended contents

Accepted local inputs may include `.pdf`, `.docx` or other readable copies of completed theses used only as contextual examples for:

- document structure and chapter ordering;
- front matter and appendices;
- academic writing style and level of detail;
- figures/tables/screenshots and captions;
- cross-references and document presentation conventions;
- methodology/results/discussion separation;
- other structural conventions relevant to writing the user's thesis.

## Important boundary

These files are **not scientific sources** for the resilient-agent thesis and do not belong in `ThesisBibliography`.

Do not copy their scientific claims, data, results, figures, code or prose into the user's thesis. They are contextual examples only and cannot override current official ICE/UNIWA guidance.

## Git / privacy

The actual example files in this folder are intentionally ignored by Git. Keep this `README.md` tracked, but do not commit third-party thesis files by default.

During `T-701`, the comparative review will produce the repository-owned derived guide:

`docs/thesis/THESIS_STRUCTURE_AND_STYLE_GUIDE.md`

That derived guide records structural/style observations without republishing the supplied theses.

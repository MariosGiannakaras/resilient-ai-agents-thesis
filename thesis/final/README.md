# Final deliverables

This directory is reserved for genuinely accepted submission/final candidates: the Microsoft Word thesis, PDF export when required, submission checklist, QA/release metadata, and release manifest.

A thesis document is not placed or described here as final merely because a build or QA workflow passes. It must also satisfy the current content/coverage target, integrate the validated scientific corrections, pass final structural/visual checks, and satisfy remaining official person/declaration and Microsoft Word field-update gates.

The previously accepted T-715 reader-scoped DOCX is now retained under `thesis/archive/` as an audit-reconciled historical milestone, not as the final thesis, because its compression was explicitly rejected on 2026-09-05.

Persistent-deliverable rules are defined in `docs/context/DELIVERABLE_RETENTION_POLICY.md`; historical milestone identities and hashes are listed in `thesis/archive/README.md`.
